# 수동 일정 (오늘 볼 포인트의 1차 소스)

`YYYY-MM-DD.yaml` 파일을 이 폴더에 두면 `topicradar collect`가 일정 신호로 읽습니다
(전날 18시에 알려진 일정으로 취급 → 아침 윈도우에 들어감). 기사 속 "오늘 ~ 예정" 문장 추출과 합쳐집니다.

```yaml
- time: "14:00"                      # 선택. 없으면 하루 일정
  title: "국회 본회의 — 연금개혁법 표결"   # '기관 — 안건' 형식이면 제목·장면 키워드가 안건 쪽으로 잡힙니다
  category: 국회                      # 선택
  url: "https://..."                 # 선택(근거 링크)
  note: "여당 단독 처리 가능성"          # 선택(편집 메모, 대본 문장으로는 쓰지 않음)
  expected: "가결이 유력하다는 전망입니다."  # 선택(아침 포인트 예상 결과로 우선 사용)
```
