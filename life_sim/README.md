# 인생 시뮬레이션

한국에서 태어나 죽을 때까지 한 사람의 인생을 사는 터미널 텍스트 게임입니다.
하고 싶은 행동을 글로 자유롭게 적으면, Claude 가 그 결과와 다음 상황을 이야기로 써 줍니다.
행동은 같은 시기 안에서 이어지고(한 번에 길어야 3개월), 해를 넘기고 싶을 때 「넘기기」로 1년이든 몇 년이든 건너뜁니다.
나이는 만 나이이고, 학년은 게임이 한국 학제(3월 새 학년, 태어난 해 + 7년에 초등학교 입학)로 계산해 이야기꾼에게 사실로 넘깁니다.
이야기꾼이 그래도 캐릭터의 학년을 다르게 쓰면 한 번 고쳐 쓰게 하고, 그래도 틀리면 게임이 학년 표기를 바로잡습니다 (유급·자퇴처럼 이야기에 이유가 있으면 그대로 둡니다).

## 웹 버전

설치 없이 브라우저에서 할 수 있는 판: `web/life.html` (claude.ai 아티팩트로 올려 둔 페이지).
보는 사람의 Claude 계정으로 이야기를 쓰고(처음 한 번 허용을 묻는다), 진행은 로그인한 사람의 저장 칸과 브라우저에 저장된다.
규칙(사건·수명·수치)은 Python 판과 같다.

## 실행

```bash
pip install -r life_sim/requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...
python3 -m life_sim          # 저장소 루트에서
```

## 플레이

- 이름과 성별, 그리고 태어난 해·고향·집안 형편·타고난 재능·출생 배경을 직접 정합니다. 비워 두면 운에 맡깁니다 (웹 버전은 타고난 능력치도 정할 수 있습니다).
- 매 턴 상황이 나오면 행동을 적습니다. 예: `친구에게 먼저 말을 건다`, `수능 대신 요리 학원에 간다`, `퇴사하고 창업한다`
- 능력치(건강·행복·지능·외모), 돈, 학력, 직업, 주변 사람이 선택에 따라 바뀝니다.
- 가끔 무작위 사건(이사, 첫사랑, 구조조정, 복권, 사고…)이 끼어들고, 남자는 스무 살 무렵 입영 통지서를 받습니다.
- 수명은 흐른 개월 수만큼 게임이 굴립니다. 이야기 밖에서 세상을 떠나면 엔딩이 마지막 장면부터 씁니다.
- 건강이 바닥나도 곧바로 죽지 않습니다. 건강은 1 아래로 내려가지 않고(한 턴에 최대 20씩 깎임) 20 아래면 「위독」 경고가 뜹니다. 이야기꾼은 캐릭터를 죽이지 않습니다. 무모한 행동이나 사고도 다치거나 위독해지는 데서 멈추고, 죽음은 나이·건강에 따른 수명 판정만 정합니다 (서른 전에는 0, 이후 나이가 들수록 커짐).
- 부고에서 「되살리기」를 고르면 죽음의 문턱에서 살아나는 장면이 이어지고, 같은 인생을 계속 삽니다 (건강은 바닥에 가깝게 남습니다).
- 나이와 건강에 따라 언젠가 세상을 떠나고, 일생을 돌아보는 엔딩(칭호·묘비명·회고)이 나옵니다.

| 명령 | 설명 |
| --- | --- |
| `/상태` | 능력치와 주변 사람 |
| `/기록` | 지금까지의 인생 기록 |
| `/넘기기 N` | N년 넘기기, N 을 빼면 1년 (그 밖의 행동은 같은 시기 안에서 이어진다) |
| `/저장` | 저장 (매 턴 자동 저장도 됩니다) |
| `/종료` | 저장하고 끝내기 — 다음 실행 때 이어서 할 수 있습니다 |

## 구조

| 파일 | 하는 일 |
| --- | --- |
| `game.py` | 캐릭터 만들기, 무작위 사건, 수명 판정, 결과 반영, 저장 (`~/.life_sim/save.json`) |
| `storyteller.py` | Claude 호출. 상태를 프롬프트로 넘기고 결과를 JSON 스키마(structured outputs)로 받는다 |
| `ui.py` | 한글 폭을 맞춘 줄 바꿈, 능력치 막대, 기다리는 표시 |
| `__main__.py` | 게임 진행 |

규칙(수명, 사건, 수치 범위)은 게임 코드가 정하고, Claude 는 이야기와 변화량만 씁니다.
매 턴 캐릭터 상태와 인생 기록을 통째로 보내기 때문에 대화 기록을 따로 쌓지 않고, 저장 파일도 단순한 JSON 입니다.

## 설정 (환경 변수)

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `LIFE_SIM_MODEL` | `claude-opus-5-5` | 쓸 모델. 더 싸게: `claude-sonnet-5-5`, `claude-haiku-5-5` |
| `LIFE_SIM_EFFORT` | `low` | 이야기에 들이는 노력. `medium`/`high` 는 더 공들이지만 느리고 비쌉니다 |
| `LIFE_SIM_SAVE` | `~/.life_sim/save.json` | 저장 파일 위치 |

한 턴에 API 를 한 번 부릅니다. 한 판은 보통 80턴 안팎입니다.
Opus 5.5 라면 한 판에 대략 몇 달러 정도로 예상하지만, 실제 비용은 직접 측정해 보지 않았습니다.
안전 분류기가 장면을 거절하면 서버가 다른 모델로 다시 쓰도록(`fallbacks: "default"`) 켜 두었습니다.

## 테스트

```bash
python3 -m unittest discover -s life_sim/tests -t .
```
