# 인생 시뮬레이션

한국에서 태어나 죽을 때까지 한 사람의 인생을 사는 터미널 텍스트 게임입니다.
해마다 하고 싶은 행동을 글로 자유롭게 적으면, Claude 가 그 결과와 다음 해의 상황을 이야기로 써 줍니다.

## 실행

```bash
pip install -r life_sim/requirements.txt
export ANTHROPIC_API_KEY=sk-ant-...
python3 -m life_sim          # 저장소 루트에서
```

## 플레이

- 이름과 성별을 정하면 태어난 해(1990~2010), 고향, 집안 형편, 타고난 재능이 무작위로 정해집니다.
- 매 턴 상황이 나오면 행동을 적습니다. 예: `친구에게 먼저 말을 건다`, `수능 대신 요리 학원에 간다`, `퇴사하고 창업한다`
- 능력치(건강·행복·지능·외모), 돈, 학력, 직업, 주변 사람이 선택에 따라 바뀝니다.
- 해마다 무작위 사건(이사, 첫사랑, 구조조정, 복권, 사고…)이 끼어들고, 남자는 스무 살에 입영 통지서를 받습니다.
- 나이와 건강에 따라 언젠가 세상을 떠나고, 일생을 돌아보는 엔딩(칭호·묘비명·회고)이 나옵니다.

| 명령 | 설명 |
| --- | --- |
| `/상태` | 능력치와 주변 사람 |
| `/기록` | 지금까지의 인생 기록 |
| `/넘기기 N` | N년(1~10)을 한꺼번에 흘려보내기 |
| `/저장` | 저장 (매 턴 자동 저장도 됩니다) |
| `/종료` | 저장하고 끝내기 — 다음 실행 때 이어서 할 수 있습니다 |

## 구조

| 파일 | 하는 일 |
| --- | --- |
| `game.py` | 캐릭터 만들기, 무작위 사건, 수명 판정, 결과 반영, 저장 (`~/.life_sim/save.json`) |
| `storyteller.py` | Claude 호출. 상태를 프롬프트로 넘기고 결과를 JSON 스키마(structured outputs)로 받는다 |
| `ui.py` | 한글 폭을 맞춘 줄 바꿈, 능력치 막대, 기다리는 표시 |
| `__main__.py` | 게임 진행 |

규칙(수명, 사건, 수치 범위)은 게임 코드가 정하고, Claude 는 이야기와 변화량만 씁니다.
매 턴 캐릭터 상태와 인생 기록을 통째로 보내기 때문에 대화 기록을 따로 쌓지 않고, 저장 파일도 단순한 JSON 입니다.

## 설정 (환경 변수)

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `LIFE_SIM_MODEL` | `claude-opus-5-5` | 쓸 모델. 더 싸게: `claude-sonnet-5-5`, `claude-haiku-5-5` |
| `LIFE_SIM_EFFORT` | `low` | 이야기에 들이는 노력. `medium`/`high` 는 더 공들이지만 느리고 비쌉니다 |
| `LIFE_SIM_SAVE` | `~/.life_sim/save.json` | 저장 파일 위치 |

한 턴에 API 를 한 번 부릅니다. 한 판은 보통 80턴 안팎입니다.
Opus 5.5 라면 한 판에 대략 몇 달러 정도로 예상하지만, 실제 비용은 직접 측정해 보지 않았습니다.
안전 분류기가 장면을 거절하면 서버가 다른 모델로 다시 쓰도록(`fallbacks: "default"`) 켜 두었습니다.

## 테스트

```bash
python3 -m unittest discover -s life_sim/tests -t .
```

Claude 대신 가짜 클라이언트를 넣어 게임 흐름(턴 진행, 저장·이어 하기, 죽음과 엔딩, 거절 처리)을 확인합니다.
