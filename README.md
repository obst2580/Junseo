# 왕조 연대기

## index.html: AI 대체역사 국가 경영 (채팅형)
실제 역사의 한 시점에서 한 나라의 통치자가 되어 채팅으로 자유롭게 어명을 내리면, AI 사관(Claude)이 결과를 이야기로 쓰고 상태창을 갱신합니다.

- 시나리오: 러시아 제국 1894, 조선 1863, 대한제국 1897, 동로마 1449, 프랑스 1789, 청 1898, 또는 직접 입력(나라, 시점, 역할, 분기점, 목표)
- 난이도: 엄격한 고증, 균형, 영웅담
- 상태창: 6개 게이지(안정도, 재정, 군사력, 산업, 민심, 국제 위상)와 변화량, 국정 지표, 위협, 주요 인물, 외교 관계
- 기억 보존: 상태창과 주요 사건 연대기를 페이지가 따로 저장했다가 매 턴 AI에게 다시 전달하므로, 대화가 길어져도 설정을 잊지 않습니다.
- 추천 어명 버튼, 시간 넘기기, 한 턴 되돌리기, (OOC: …) 메타 요청을 지원합니다.
- AI 응답은 claude.ai 아티팩트로 열었을 때만 동작합니다(보는 사람의 Claude 계정 사용량 사용).
- claude.ai에서 열면 진행 상황이 계정별 비공개 저장소에 저장되어 휴대폰과 컴퓨터에서 이어서 할 수 있습니다. 새 시나리오 화면에 저장된 게임 목록이 나옵니다.

## classic.html: 버튼형 턴제 국가 경영
AI 없이 동작하는 첫 번째 버전입니다. 여섯 시대, 건설, 주변국 외교·전쟁, 선택형 사건이 있습니다.

진행 상황은 모두 브라우저 localStorage에 저장됩니다.
