# Junseo

## 80억 분의 1 (`eight-billion/`)

지금 다시 태어난다면 어느 나라, 어떤 집에서 누구로 태어날지 뽑고, 그 삶을 한 해씩 지켜보는 인생 시뮬레이션입니다. [1in8b.life](https://1in8b.life/)에서 아이디어를 얻었습니다.

- 태어날 나라는 139개국의 연간 출생아 수(또는 인구)에 비례해 정해집니다.
- 수명, 아동 사망, 소득 분포(지니계수), 교육, 조혼, 출산, 분쟁·질병 위험은 공개 통계를 바탕으로 한 근사치를 따릅니다.
- 여섯 살부터 해마다 무엇에 집중할지(공부·일·사랑·가족·건강·배움·쉼 등) 고르고, 진학·첫 일·결혼·아이·이민·피란·치료의 갈림길에서 결정합니다. 선택지마다 그 나라 소득·의료 수준에 따라 다른 가능성이 표시됩니다.
- 직접 고르지 않거나 자동 모드로 두면 그 나라에서 흔한 선택을 따르고, 이렇게 자동으로 산 삶의 평균 수명은 각 나라 기대수명과 맞도록 보정했습니다.
- 같은 순간 다른 곳에서 태어난 네 아이가 같은 통계로 나란히 살아갑니다.
- 한 삶의 길이는 1시간·10분·3분·빠르게 중에서 고릅니다(1년 = 고른 시간 ÷ 그 나라 기대수명).
- 삶이 끝나면 어떤 삶이었는지 남기고, 추모관에서 촛불을 켤 수 있습니다. 파일로 열면 이 브라우저에만 저장됩니다.

실행: `eight-billion/index.html`을 브라우저로 열면 됩니다. 빌드 과정이나 서버가 필요 없습니다.
