# 준서 시티 (JunseoCity) — 마인크래프트판 FiveM 인생모드

GTA5 FiveM **「인생모드」**를 마인크래프트 **Java 에디션**으로 옮기는 도시 생활 RP 서버 플러그인입니다.

- 경찰·의료국은 **사람이** 맡습니다.
- 모든 기능은 **스마트폰(G키)**과 **클릭**으로 씁니다. 명령어는 관리자만 씁니다.
- 동접 **500명**을 목표로 처음부터 **Folia(멀티스레드 서버) 호환**과 **DB 저장**으로 만들었습니다.

> 빌드와 자동 테스트는 통과했지만, 실제 서버에서 같이 플레이하며 다듬어야 합니다.

## 지금 되는 것 (v0.2.0)

| 기능 | 내용 |
|---|---|
| **입국 심사 · 캐릭터** | 처음 들어오면 규칙 동의 → 캐릭터 이름 입력(**딱 한 번**, 바꿀 수 없음) → **주민번호 자동 발급**(예: `261004-1000001`) → 스마트폰·신분증·정착금 지급 |
| **스마트폰 (G키)** | **G키**(바닐라 「빠른 동작」 키) 또는 폰 우클릭으로 열립니다. ESC 메뉴에도 버튼이 있습니다. 앱 8개는 아래 표를 보세요 |
| **사람 우클릭 메뉴** | 빈손으로 사람을 우클릭하면 [신분증 보여주기] [현금 건네기] |
| **클릭만으로 금액 고르기** | [+1천][+1만][+10만][+100만][-1천][-1만][초기화][최대] → [확인] |
| **112 / 119** | 신고 사유를 버튼으로 고르면 위치와 함께 경찰/의료국 직업 플레이어에게 알림이 가고, **[응답]**을 누르면 길 안내가 시작됩니다 |
| **자동 신고** | 총소리, 강도, 차량 도난이 일어나면 경찰에게 자동으로 알림이 갑니다 |
| **강도** | 총을 들고 금고를 우클릭하면 시작합니다. **접속 중인 경찰이 N명 이상일 때만** 가능합니다(편의점 2명, 은행 4명) |
| **상점 NPC** | 편의점, 총포상, 자동차 대리점, 광물 거래소, 직업소개소, 택배물류센터, 은행원 |
| **총 · 자동차** | 총: 우클릭 발사, F 재장전<br>자동차: 열쇠로 소환, WASD 운전, 경찰차 사이렌 |
| **미니맵 (GTA 레이더)** | 아무것도 들지 않아도 **화면 아래 핫바 왼쪽에 늘** 떠 있습니다. 보는 방향이 위, 걸을 때 약 580×380m, 차를 타면 약 960×640m를 보여 줍니다<br>내 화살표, 북쪽(N), 길 안내 목적지, 주요 장소 아이콘이 나옵니다 |
| **큰 지도 (F키)** | **F키**로 도시 전체 지도가 열립니다. 북쪽이 위이고 [＋][－]로 도시 → 구역 → 동네 확대, 화살표로 이동합니다<br>지도에 **마우스를 올리면 구역·장소 이름**, **누르면 그곳으로 길 안내**가 켜집니다. 총을 들고 있으면 F는 재장전, **Shift+F**는 원래대로 손 바꾸기 |
| **리소스팩 (자동)** | 미니맵·큰 지도 그림은 접속할 때 **자동으로 받는 리소스팩**입니다. 모드 설치는 필요 없습니다. 서버가 직접 나눠 줍니다(포트 8163) |
| **저장** | SQLite(기본) 또는 MySQL/MariaDB. 송금·월급 같은 돈 기록이 남습니다 |

스마트폰 앱 8개:

| 앱 | 하는 일 |
|---|---|
| 은행 | 잔액, 근처 사람에게 송금, 거래내역. 입금·출금은 ATM 근처에서 |
| 내 정보 | 이름, 주민번호, 직업. 신분증 재발급 |
| 긴급 신고 | 112 경찰 · 119 구조 |
| 직업 | 시민·택배기사·광부 바로 변경. 경찰·의료국은 채용 필요 |
| 알바 | 택배 배달 미션 |
| 차고 | 내 차 위치, 길 안내, 차고에 넣기 |
| 지도 | 큰 지도 열기, 병원·ATM·상점 등으로 길 안내 |
| 관리자 호출 | 버그·신고·도움 요청 |

## 1. 내 PC에서 서버 열기

### 준비물
1. **Java 25:** [Adoptium Temurin 25](https://adoptium.net/temurin/releases/?version=25)
2. **서버 jar:** 아래 둘 중 하나를 받아서 `server/paper.jar` 이름으로 저장합니다.
   - [Paper](https://papermc.io/downloads/paper) 26.2: 테스트·소규모
   - [Folia](https://papermc.io/downloads/folia) 26.2: 대규모
3. **플러그인 jar:** GitHub 저장소 **Actions** 탭 → 가장 최근 성공한 *Build* → 아래쪽 *Artifacts*의 `JunseoCity-plugin`
   - 직접 빌드하려면 `gradlew.bat build` (Windows) 또는 `./gradlew build` → `build/libs/`

### 실행
1. `server/plugins/`에 `JunseoCity-0.2.0.jar`를 넣습니다.
2. `server/start.bat`(Windows)이나 `server/start.sh`(macOS/Linux)를 실행합니다. 처음에는 EULA 동의를 물어봅니다.
3. 마인크래프트 → 멀티플레이 → `localhost`로 접속하면 **입국 심사(캐릭터 만들기)** 화면이 뜹니다.
4. 서버 창에 `op 내닉네임`을 입력해 관리자가 됩니다.
5. 게임 안에서 **G키**를 누르면 스마트폰이 열립니다.
   - 안 열리면: 설정 → 조작 → 「빠른 동작」 키를 확인하세요.

> **개발자 지름길:** `./gradlew runServer`를 실행하면 Paper를 자동으로 받아 플러그인을 넣고 서버를 띄웁니다.

6. 처음 들어올 때 **리소스팩을 받을지** 물어보면 **예**를 누릅니다. 미니맵이 핫바 왼쪽에 나오고, **F키**로 큰 지도가 열립니다.
   - 서버 창에 `리소스팩 준비 완료 ... 내장 웹 서버 포트 8163`이 보이면 정상입니다.
   - 미니맵이 안 나오면: 서버 목록 → 서버 선택 → 편집 → 「서버 리소스팩」을 **사용**으로 바꾸고 다시 들어오세요.
   - 미니맵은 서버의 도시 설계도 기준이라, 아직 도시가 지어지지 않은 월드에서는 실제 땅과 다르게 보입니다. 도시 월드는 [`mapgen/README.md`](mapgen/README.md)로 만듭니다.

### 친구가 들어오려면
- **같은 공유기:** 서버 PC의 내부 IP(예: `192.168.0.10`)로 접속합니다.
- **다른 집:** 25565 포트 포워딩을 하거나 호스팅을 쓰세요. **리소스팩 포트 8163(TCP)도 함께 열어야** 미니맵이 보입니다.
  - 포트를 더 열 수 없는 호스팅이면 `plugins/JunseoCity/resourcepack/JunseoCity-pack.zip`을 웹에 올리고 `config.yml`의 `resource-pack.url`에 그 주소를 넣으세요.

## 2. 도시 꾸미기 (관리자)

### 장소 지정
**그 자리에 서서** 입력:

| 명령어 | 의미 |
|---|---|
| `/시티관리 place set spawn` | 처음 오는 곳 |
| `/시티관리 place set hospital` | 죽으면 깨어나는 병원 |
| `/시티관리 place set jail` | 감옥 |
| `/시티관리 place set jail_exit` | 출소하는 곳 |
| `/시티관리 place set delivery_point 이름` | 택배 배달지 (많을수록 좋아요) |

**블록을 바라보고** 입력:

| 명령어 | 의미 |
|---|---|
| `/시티관리 place set atm` | ATM (우클릭하면 은행 화면) |
| `/시티관리 place set store_safe 편의점1` | 편의점 금고 |
| `/시티관리 place set bank_vault 중앙은행` | 은행 금고 |

목록은 `place list`, 삭제는 `place remove`(가장 가까운 장소)입니다.

### NPC 세우기
세울 자리에 서서 입력합니다. 세운 NPC는 폰 지도 앱에 자동으로 나옵니다. 지우려면 크리에이티브 모드에서 때리세요.
```
/시티관리 npc convenience | gunstore | cardealer | mineral | jobcenter | depot | banker
```

### 그 밖의 관리자 명령어
```
/시티관리 info <닉네임>                              캐릭터 정보
/시티관리 job <닉네임> police|ems [계급]              경찰·의료국 채용 (사람이 하는 공무직)
/시티관리 money <닉네임> <set|add|take> <금액> [cash|bank]
/시티관리 jail <닉네임> <초>   /시티관리 release <닉네임>
/시티관리 give <phone|idcard|pistol|ammo|handcuffs|key_police ...> [개수] [닉네임]
/시티관리 reload                                     config.yml 다시 읽기
```
`/시티관리` 대신 `/cityadmin`을 써도 됩니다.

## 3. 설정과 데이터

`server/plugins/JunseoCity/config.yml`에서 바꿀 수 있는 것:
- 서버 이름, 정착금, 병원비, 월급
- 강도 최소 경찰 수와 보상
- 상점 가격, 광물 판매가
- 데이터베이스 종류
- 리소스팩 포트·주소 (`resource-pack`), 미니맵 위치(왼쪽/오른쪽)·범위·갱신 간격 (`minimap`)

**데이터 저장 위치**
- **SQLite(기본):** `plugins/JunseoCity/city.db` 파일 하나에 저장합니다. 내 PC에서 테스트하거나 사람이 적을 때 씁니다.
- **MySQL/MariaDB:** `database.type: mysql`로 바꾸고 접속 정보를 넣습니다. 수백 명 규모에서 씁니다.
- 장소는 `plugins/JunseoCity/places.yml`에 저장됩니다.

**호스팅으로 옮길 때** 아래를 그대로 업로드하면 됩니다. MySQL을 쓰면 DB만 연결합니다.
- 월드 폴더
- `plugins/JunseoCity-0.2.0.jar`
- `plugins/JunseoCity/` 폴더 (city.db 포함)

## 4. 개발 정보

```
src/main/java/com/junseo/city/
├── JunseoCity.java / JunseoBootstrap.java   시작점 (서비스 연결 / G키 데이터팩 등록)
├── character/   입국 심사·캐릭터 생성
├── data/        DB (SQLite·MySQL), 캐릭터 저장소
├── ui/          클릭 화면(대화창) 프레임워크, 금액 고르기
├── phone/       스마트폰 앱, 112/119 신고, 길 안내, 사람 우클릭 메뉴
├── map/         미니맵(액션바)·큰 지도(대화창): 설계도로 그린 도시 그림을 글자로 그림
├── pack/        리소스팩(글꼴) 만들기·내장 웹 서버·접속 시 보내기
├── hud/         사이드바, 액션바 한 줄 나눠 쓰기(미니맵 + 알림), 글자 폭 표
├── logic/       서버 없이 테스트하는 순수 로직 (돈, 이름 규칙, 주민번호, 자동차 물리)
├── economy/ shop/ npc/ job/ crime/ weapon/ vehicle/ place/
src/main/resources/datapack/   G키·ESC 메뉴에 스마트폰을 연결하는 데이터팩
```

- **Folia 호환:** 메인 스레드를 가정하지 않고, 플레이어·엔티티·위치 단위 스케줄러를 씁니다(`util/Sched`). 공유 데이터는 스레드 안전 구조를 씁니다.
- **빌드:** `./gradlew build` (JDK 25)
- **테스트:** `./gradlew test` — 돈·송금 동시성, 이름 규칙, 주민번호, SQLite 저장소, 자동차 물리를 검사합니다.
  - 미니맵·큰 지도는 클라이언트의 글자 그리기 규칙을 흉내 내서 **한 칸도 틀리지 않고** 그려지는지 검사합니다.
  - `./gradlew test -DmapPreview=true` → `build/preview/`에 미니맵·큰 지도 미리보기 그림이 생깁니다.
- **CI:** GitHub에 올리면 Actions가 빌드하고 jar를 Artifacts로 올립니다.
- **도시 설계도 계산:** `citymap/` 공용 모듈입니다. 설계도 `map/layout.json`을 계산하고, 생성기와 미니맵이 함께 씁니다.
- **도시 바탕 생성기:** `mapgen/` 모듈(`JunseoMapGen-*.jar`)입니다.
  - 설계도 `map/layout.json`으로 땅·한강·바다·산·도로·다리·터널이 깔린 빈 도시 월드를 만듭니다.
  - 건축 서버용입니다. 사용법은 [`mapgen/README.md`](mapgen/README.md)를 보세요.
