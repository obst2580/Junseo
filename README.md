# 왕조 연대기

작은 부족에서 시작해 여섯 시대(부족 → 고대 → 중세 → 르네상스 → 산업 → 근대)를 거치며 나라를 키우는 턴제 국가 경영 게임입니다. 설치 없이 `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

## 플레이 방법
- 해마다 행동력만큼 명령을 내립니다: 영토 개척, 징병, 학문 장려, 축제, 건설(농장·시장·병영·신전·학당·성벽·항구·공장).
- 세율(감세/보통/중세)은 행동력 없이 바꿀 수 있습니다.
- 주변 4개국과 예물·동맹·선전포고·진격·화친으로 외교합니다. 나라마다 성향(호전적·중립적·온건한·상업적)이 다릅니다.
- 한 해를 마치면 수입이 정산되고 이웃이 움직이며, 선택지가 있는 사건(풍년, 역병, 금광, 항해가, 파업 등)이 일어납니다.

## 승리 / 패배
- 승리: 모든 이웃 합병(천하 통일) 또는 근대에 만국 박람회 개최(문명의 정점)
- 패배: 영토 상실, 민심 0(민중 봉기), 인구 소멸

진행 상황은 브라우저 localStorage에 자동 저장됩니다.
