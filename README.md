# 준서 시티 (JunseoCity)

GTA / FiveM "인생모드" 스타일의 마인크래프트 **Java 에디션** 서버 플러그인입니다.
돈을 벌고, 직업을 갖고, 차를 몰고, 가끔은 강도도 하고… 경찰에게 쫓기는 도시 생활 RP 서버를 만듭니다.

- 서버: [Paper](https://papermc.io) 26.2 이상 (26.3 에서도 동작)
- 친구들은 **모드 설치 없이** 일반 마인크래프트로 접속합니다.
- 모든 안내 메시지는 한국어입니다.

> 지금 버전(0.1.0)은 첫 버전이에요. 빌드와 자동 테스트는 통과했지만, 실제 서버에서 같이 놀아 보면서
> 손볼 부분(차 핸들링 느낌, 경찰 난이도, 가격 등)이 나올 거예요. 그때그때 고쳐 나가요.

## 기능 한눈에 보기

| 분야 | 내용 |
|---|---|
| **돈 · 은행** | 현금과 은행 잔액이 따로 있어요. ATM/은행원에서 입금·출금, `/송금`. 죽으면 현금 20%를 병원비로 잃으니 은행에 넣어 두세요. |
| **상점** | NPC 상점: 편의점(음식·붕대), 총포상(총·총알·방탄조끼), 자동차 대리점, 광물 거래소(광물 팔기). 현금이 모자라면 카드(은행)로 자동 결제. |
| **직업 · 월급** | 시민 / 경찰 / 택배기사 / 광부. 10분마다 직업별 월급이 은행으로 들어와요. |
| **미션** | 택배기사: 택배 상자를 들고 배달지까지 제한 시간 안에 가면 돈! (화살표 보스바 안내, 빨리 가면 보너스) |
| **수배 ★** | 폭행·살인·차량 절도·강도를 하면 별(최대 5개)이 올라요. 경찰에게서 멀리 도망쳐 숨어 있으면 별이 줄어요. 별 3개부터는 몸이 빛나서 위치가 들켜요. |
| **경찰** | 별 2개부터 AI 경찰이 출동(3개부터 석궁 든 특공대). 경찰 직업 플레이어는 수갑으로 수배자를 체포하고 보상을 받아요. 경찰에게 잡히거나 죽으면 **BUSTED** → 감옥. |
| **강도** | 총을 들고 편의점/은행 금고를 우클릭 → 정해진 시간 동안 금고 근처에서 버티면 돈! 경찰에 신고가 들어가고 경보가 울려요. |
| **총** | 권총·산탄총·소총, 경찰 전용 테이저건. 우클릭 발사, F 재장전, 헤드샷 1.5배, 총알은 따로 구매. |
| **자동차** | 경차·세단·스포츠카·경찰차. 열쇠로 소환해서 WASD로 운전, 경적/사이렌, 사람 치면 피해, 남의 차를 타면 차량 절도! |
| **화면** | 오른쪽 사이드바에 현금·은행·직업·수배·배달 거리, GTA 스타일 WASTED / BUSTED 화면. |

## 1. 내 PC에서 서버 열기

### 준비물
1. **Java 25** 설치 — [Adoptium Temurin 25](https://adoptium.net/temurin/releases/?version=25) (JDK 또는 JRE)
2. **Paper 서버 jar** — [papermc.io/downloads/paper](https://papermc.io/downloads/paper)
   - 친구들 마인크래프트 버전과 같은 버전을 받으세요 (예: 26.3 으로 플레이하면 Paper 26.3).
   - 받은 파일 이름을 `paper.jar` 로 바꿔서 이 저장소의 `server/` 폴더에 넣으세요.
3. **이 플러그인 jar** (`JunseoCity-0.1.0.jar`) — 둘 중 하나
   - **쉬운 방법:** GitHub 저장소의 **Actions** 탭 → 가장 최근 성공한 *Build* 실행 → 아래쪽 *Artifacts* 의
     `JunseoCity-plugin` 을 받아서 압축을 풀기
   - **직접 빌드:** 저장소 폴더에서 `gradlew.bat build` (Windows) 또는 `./gradlew build` → `build/libs/` 에 생겨요.

### 실행
1. `server/plugins/` 폴더에 `JunseoCity-0.1.0.jar` 를 넣어요. (폴더가 없으면 만들기)
2. Windows는 `server/start.bat` 더블클릭, macOS/Linux는 `server/start.sh` 실행.
   처음 한 번은 마인크래프트 EULA 동의를 물어봐요.
3. 서버 창에 `Done` 이 나오면 준비 완료! 마인크래프트 → 멀티플레이 → 서버 주소 `localhost`.
4. 서버 창에 `op 내닉네임` 을 입력해서 관리자 권한을 받으세요.
5. `server/server.properties` 에서 `difficulty=easy` 이상인지 확인하세요. (**peaceful 이면 AI 경찰이 안 나와요**)

> 개발자용 지름길: JDK 25 가 있으면 저장소 폴더에서 `./gradlew runServer` 한 번으로
> Paper 를 자동으로 받아 플러그인을 넣고 서버를 띄웁니다 (`run/` 폴더 사용).

### 친구가 들어오려면
- **같은 와이파이/공유기:** 서버 PC의 내부 IP(예: `192.168.0.10`)로 접속. (Windows: `ipconfig` 의 IPv4 주소)
- **다른 집에서:** 공유기에서 **25565 포트 포워딩**이 필요해요. 어렵다면 아래 "호스팅으로 옮기기"가 더 편해요.

## 2. 처음 시티 꾸미기 (관리자 체크리스트)

관리자(OP)는 `/시티관리` 명령어로 장소와 NPC를 지정해요. 먼저 도시를 지어 두고 하나씩 정하면 돼요.

### 장소 지정 — 그 자리에 서서 입력
| 명령어 | 의미 |
|---|---|
| `/시티관리 place set spawn` | 처음 접속한 사람이 나타나는 곳 |
| `/시티관리 place set hospital` | 죽으면 깨어나는 병원 |
| `/시티관리 place set jail` | 감옥 (이 자리에서 20칸 넘게 벗어나면 끌려와요) |
| `/시티관리 place set jail_exit` | 출소하면 나오는 곳 |
| `/시티관리 place set delivery_point 철수네집` | 택배 배달지 (여러 개 만들수록 좋아요) |

### 블록 지정 — 블록을 바라보고 입력
| 명령어 | 의미 |
|---|---|
| `/시티관리 place set atm` | 바라보는 블록이 ATM (우클릭하면 은행 메뉴) |
| `/시티관리 place set store_safe 편의점1` | 편의점 금고 (총 들고 우클릭 = 강도) |
| `/시티관리 place set bank_vault 중앙은행` | 은행 금고 (보상이 크고 별이 더 많이 올라요) |

`/시티관리 place list` 로 목록을 보고, `/시티관리 place remove` 로 가장 가까운 장소를 지워요.

### NPC 세우기 — 세우고 싶은 자리에 서서 입력
```
/시티관리 npc convenience   편의점
/시티관리 npc gunstore      총포상
/시티관리 npc cardealer     자동차 대리점
/시티관리 npc mineral       광물 거래소
/시티관리 npc jobcenter     직업 소개소
/시티관리 npc depot         택배 물류센터
/시티관리 npc banker        은행원
```
NPC를 없애려면 크리에이티브 모드에서 때리면 돼요.

### 그 밖의 관리자 명령어
```
/시티관리 money <이름> <set|add|take> <금액> [cash|bank]
/시티관리 job <이름> <citizen|police|delivery|miner>
/시티관리 wanted <이름> <0~5>
/시티관리 jail <이름> <초>     /시티관리 release <이름>
/시티관리 give <pistol|shotgun|rifle|taser|ammo|handcuffs|bandage|key_sports ...> [개수] [이름]
/시티관리 reload               config.yml 다시 읽기
```

## 3. 플레이 방법

| 명령어 | 설명 |
|---|---|
| `/도움말` | 전체 도움말 |
| `/돈` | 현금 · 은행 잔액 |
| `/은행` | ATM 메뉴 (ATM·은행원 근처에서) — `/은행 입금 1만`, `/은행 출금 전부` |
| `/송금 이름 금액` | 은행 송금 |
| `/직업` | 직업 고르기 |
| `/택배` · `/택배 취소` | 택배 배달 시작 / 취소 (택배기사) |
| `/수배자` | 수배자 목록과 거리 |
| `/112 내용` | 경찰 플레이어에게 신고 |
| `/차` · `/차 회수` | 자동차 조작법 / 내 차 모두 넣기 |

**총:** 우클릭 발사 · F 재장전 · 총알은 총포상
**자동차:** 열쇠 들고 땅 우클릭 = 꺼내기 · 웅크리고 우클릭 = 넣기 · 차 우클릭 = 타기
W/S 가속·후진 · A/D 핸들 · 스페이스 브레이크 · Ctrl 경적(경찰차는 사이렌) · Shift 내리기 · F5 뒤에서 보기
**강도:** 총을 들고 금고 우클릭 → 금고 근처에서 버티기
**경찰:** `/직업` 에서 경찰 → 수갑·테이저·권총·경찰차 열쇠 지급 → 수배자를 수갑으로 때리면 체포

## 4. 설정 바꾸기

`server/plugins/JunseoCity/config.yml` 에서 서버 이름, 시작 돈, 병원비, 월급, 수배 감소 시간,
AI 경찰 수, 강도 보상, 상점 가격, 광물 판매가 등을 바꿀 수 있어요.
바꾼 뒤 게임에서 `/시티관리 reload`.

플레이어 데이터는 `plugins/JunseoCity/players/`, 장소는 `plugins/JunseoCity/places.yml` 에 저장돼요.

---

## 5. 호스팅으로 옮기기

1. 호스팅 서비스에서 **Paper**, 내 PC와 **같은 마인크래프트 버전**, **Java 25** 를 고르세요.
2. 내 PC 서버를 끈 뒤(`stop`) 다음을 그대로 업로드하면 이어서 플레이할 수 있어요.
   - `world`, `world_nether`, `world_the_end` 폴더 (도시 맵)
   - `plugins/JunseoCity-0.1.0.jar`
   - `plugins/JunseoCity/` 폴더 전체 (돈·직업·장소 데이터)
   - `server.properties`, `ops.json` (선택)
3. 호스팅 서버를 켜고 접속 주소를 친구들에게 알려 주면 끝!

## 6. 개발 정보

```
src/main/java/com/junseo/city/
├── JunseoCity.java        플러그인 시작점 (서비스 연결, 타이머)
├── Settings.java          config.yml 읽기
├── PlayerListener.java    접속/퇴장, WASTED/BUSTED, 붕대
├── logic/                 서버 없이 테스트하는 순수 로직 (돈, 수배, 자동차 물리, 나침반)
├── data/                  플레이어 데이터 저장 (YAML)
├── place/                 병원·감옥·ATM 등 장소
├── economy/ shop/ menu/   은행, 상점, 상자 메뉴
├── npc/                   상점 NPC
├── job/                   직업, 월급, 택배 미션
├── crime/                 수배, AI 경찰, 감옥, 강도, 범죄 감지
├── weapon/                총
├── vehicle/               자동차
└── command/               명령어
```

- 빌드: `./gradlew build` (JDK 25 필요) → `build/libs/JunseoCity-0.1.0.jar`
- 테스트: `./gradlew test` — `logic/` 의 돈 계산, 수배 규칙, 자동차 물리, 방향 화살표를 검사해요.
- GitHub에 푸시하면 Actions 가 자동으로 빌드해서 jar 를 *Artifacts* 로 올려요.
