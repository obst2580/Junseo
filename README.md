# 국가의 시대 · 기업의 시대

같은 엔진으로 도는 텍스트 시뮬레이션 두 편입니다.

- **국가의 시대**: 역사 기반 통치 시뮬레이션. 플레이어는 군주가 되어 왕명을 내리고, 조정은 그 명령을 쉽게 따르지 않습니다. 관료는 이견을 내고, 국고는 모자라고, 지방은 버팁니다.
- **기업의 시대**: 시대 기반 경영 시뮬레이션. 플레이어는 대표가 되어 지시를 내리고, 임원 회의는 비용과 위험을 따집니다. 재무팀은 반대하고, 이사회는 제동을 걸고, 노조와 고객은 반발합니다.

아래 설명은 국가의 시대 용어로 적었습니다. 기업의 시대는 같은 규칙에 이름만 바뀝니다([기업의 시대](#기업의-시대) 참고).

## 설계 원칙: 규칙은 엔진이, 서술은 Claude가

이 게임의 핵심 요구는 "뭔가 좀 안 풀리는 게 있어야 진짜 내가 통치하는 느낌"입니다. 언어 모델에게 "가끔 반대하라"고만 지시하면 결국 플레이어 말에 맞춰 주기 쉽습니다. 그래서 결과는 엔진이 먼저 정하고, Claude는 그 결과가 **왜** 그렇게 되었는지를 조정 회의 기록으로 풀어내도록 역할을 나눴습니다.

| 맡는 쪽 | 하는 일 |
| --- | --- |
| 엔진 (`src/engine.js`) | 실행 판정 주사위, 돌발 사건, 장기 미결 안건, 날짜 계산, 상태창 변동 보정, 인물·정책·세력 기억, 기록 검증 |
| Claude (`src/prompt.js`로 지시) | 관료들의 발언과 논의, 오늘의 뉴스, 상태창 수치 제안, 새 인물과 정책, 기록 충돌 감지 |

### 실행 판정

왕명을 내릴 때마다 엔진이 1~100 주사위를 굴리고 조정 기류의 보정치를 더해 등급을 정합니다.

| 점수 | 판정 | 결과 |
| --- | --- | --- |
| 1–30 | 순조 | 시행. 그래도 소수 의견이나 우려 하나는 기록 |
| 31–65 | 조건부 | 수정안, 단계적 시행, 예외 조항이 붙어 일부만 시행 |
| 66–80 | 지연 | 재원·인력·시기 문제로 보류되고 미결 안건으로 남음 |
| 81–93 | 반발 | 시행되지만 특정 세력이 상소, 사직, 불복으로 맞섬 |
| 94 이상 | 좌초 | 반려되거나 시행 직후 무력화 |

보정치가 없으면 왕명의 약 65%가 시행(순조·조건부)되고 35%는 막힙니다. 보정치(화면의 **조정 기류**)는 다음 사정으로 바뀌고, 화면에 "왕명이 받아들여질 가능성 약 N%"로 보입니다.

- 국민 여론 25 미만 +12, 40 미만 +5, 70 이상 −5
- 국고 적자 +8
- 세력 지지도 평균 35 미만 +8, 65 이상 −5
- 연이은 성사: 두 번째부터 1회마다 +3 (최대 +9). 너무 잘 풀리면 조정이 견제합니다.
- 앞선 차질: 1회마다 −8 (최대 −24). 막히고 나면 조정도 타협을 찾습니다.
- 미결 안건 재론: 논의중·보류인 정책 이름을 넣어 다시 명하면 −10 (정책 탭의 **재론하기**)
- 조정의 협조(난이도): 온건 −15, 표준 0, 혹독 +15. 게임 도중에도 **기록 관리**에서 바꿀 수 있습니다.

Claude는 판정보다 유리한 결과를 쓰지 못합니다. 판정은 같은 턴에 같은 명령을 다시 내려도 다시 굴리지 않으므로, 중단하고 다시 내려서 결과를 바꿀 수 없습니다.

### 시간의 흐름

왕명 한 번은 조정 회의 며칠 사이의 일입니다. 걸리는 날수는 엔진이 판정에 따라 정하고(순조 1–3일, 조건부 2–6일, 지연 5–12일, 반발 2–7일, 좌초 1–4일), Claude에게는 몇 달 뒤의 결과를 앞당겨 쓰지 말고 결정과 시행 착수, 즉각적인 반응까지만 기록하게 합니다. 날짜는 한 달을 30일로 세는 게임 달력을 씁니다. 몇 달, 몇 년은 시간 경과 명령으로만 흐릅니다.

### 돌발 사건과 시간 경과

- 왕명 턴에는 10% 확률(국민 행복도가 낮거나 적대국이 있으면 더 높음)로 돌발 사건이 끼어듭니다.
- "보름 후", "다음 달", "1년 후", "3년이 흐른다" 같은 명령이나 시간 경과 버튼으로 시간을 보낼 수 있습니다. 기간이 길수록 사건이 많아지고(5년이면 2~3건), 기존 정책의 진척도 판정을 받습니다.
- 사건 범주는 자연재해, 역병, 외교, 국경·군사, 정치, 민생·경제, 인물, 길보이며 그때의 상태에 따라 가중치가 달라집니다.
- 5턴 넘게 묵은 미결 안건은 관료가 다시 꺼내거나 흐지부지 폐기됩니다.

### 기억과 검증

Claude는 대화를 기억하지 않으므로, 엔진이 세계 기록(고정 설정, 상태창, 인물 명부, 정책 기록, 세력, 지역, 연대기, 직전 기록 원문)을 매 턴 프롬프트에 넣습니다. 응답이 오면 엔진이 검증합니다.

- **사망한 인물이 발언하면** 오류 목록을 붙여 한 번 고쳐 쓰게 합니다.
- **상태창이 기간에 비해 터무니없이 움직이면** 상한까지만 반영하고, 기록 아래 "사관 검증"에 보정 사실을 남깁니다(예: 한 차례 회의에서 여론은 ±12까지).
- **동맹국과 적대국에 같은 나라가 오르면** 적대국으로 정리합니다.
- 날짜와 재정·GDP 단위는 엔진이 관리하므로 거꾸로 가거나 바뀌지 않습니다.
- 명령이 기록과 충돌하면(이미 시행된 제도의 재도입 등) 기록을 멈추고 ⚠️ 경고와 함께 세 가지 선택지를 줍니다: (1) 기존 설정 기준 진행, (2) 현재 지시 우선으로 덮어쓰기, (3) 세계관 요약을 고쳐 재동기화.

## 실행하기

### claude.ai에서

게시된 아티팩트를 열면 보는 사람의 Claude 계정으로 사관이 기록합니다. 첫 기록 때 Claude 사용을 허용할지 묻습니다. 진행 상황은 브라우저에 자동 저장되며, **기록 관리**에서 저장 기록을 복사하거나 파일로 내보내고 다시 불러올 수 있습니다.

### 로컬 서버로

```bash
npm install
npm run build
ANTHROPIC_API_KEY=sk-ant-... npm start
# 국가의 시대  http://127.0.0.1:8787/
# 기업의 시대  http://127.0.0.1:8787/business
```

| 환경 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | — | Anthropic API 키. 서버에만 있고 브라우저로 보내지 않습니다. |
| `GUKGA_MODEL` | `claude-opus-5-5` | 사관 모델 |
| `PORT` / `HOST` | `8787` / `127.0.0.1` | 서버 주소 |

서버는 `server.mjs` 하나이며 Anthropic TypeScript SDK로 응답을 스트리밍합니다. 화면의 **사관의 깊이**(신속·표준·신중)는 effort(low·medium·high)로 전달됩니다. Opus 5.5 같은 모델에서는 안전 분류기가 요청을 거절할 때 서버 측 대체 모델(`fallbacks: "default"`)로 이어 쓰도록 켜 두었습니다.

### 화면 점검용 가짜 기록자

주소 끝에 `#mock`을 붙이면(`http://127.0.0.1:8787/#mock`, `http://127.0.0.1:8787/business#mock`) Claude 없이 미리 만든 응답으로 화면 흐름을 확인할 수 있습니다. 판정, 충돌, 시간 경과가 모두 동작하지만 서술은 고정된 문장입니다.

## 구조

```
src/
  engine.js        판정·사건·검증·기록 병합 (DOM과 네트워크를 모르는 순수 로직)
  prompt.js        프롬프트의 틀과 순서 (문구는 모드에서)
  llm.js           Claude 연결: claude.ai sample 기능 / 로컬 서버 / 가짜 기록자
  main.js          화면과 진행 (boot(모드)로 시작)
  modes/
    kingdom.js     국가의 시대: 문구, 상태창 항목, 사건, 규칙 프롬프트, 시나리오
    business.js    기업의 시대: 같은 모양의 회사판
  entry-*.js       게임별 진입점
  body.html        화면 뼈대 ({{키}} 자리에 모드 문구가 들어감)
  styles.css       실록 지면을 본뜬 기본 스타일 (라이트·다크)
  theme-business.css  기업의 시대 덧칠: 모눈 업무 수첩, 회의록 서식, 둥근 직인
scripts/build.mjs  게임마다 한 장짜리 HTML로 묶음 → dist/
server.mjs         로컬 서버
test/              엔진·프롬프트·사업 모드 단위 테스트 (node:test)
```

새 무대를 더하려면 `modes/kingdom.js`와 같은 모양의 모드 파일을 만들고 `modes/index.js`와 `scripts/build.mjs`에 등록하면 됩니다. 두 모드가 같은 문구 키를 모두 갖췄는지는 테스트가 확인합니다.

```bash
npm test
```

## 기업의 시대

국가의 시대와 같은 판정 주사위, 며칠 단위 시간, 돌발 사건, 기록 검증을 그대로 씁니다. 바뀌는 것은 무대입니다.

| 국가의 시대 | 기업의 시대 |
| --- | --- |
| 군주, 왕명, 하명 | 대표, 지시 |
| 조정 회의, 관료 | 경영 회의, 임원진 |
| 사관, 실록체 | 회의록 서기, 보고체 |
| 인구, 동맹국, 적대국 | 직원 수, 협력사, 경쟁사 |
| 국민 여론, 국민 행복도 | 고객 평판, 직원 만족도 |
| 재정, GDP | 현금, 연 매출 |
| 세력·계층 | 이해관계자 (이사회, 투자자, 노조, 고객, 협력사) |
| 재론하기 | 재검토하기 |
| 결재 도장: 시행 | 직인: 승인, 조건부 승인, 반려 |

- **돌발 사건**: 시장 변동, 경쟁사 공세, 규제·법률, 사고, 인사, 노사·조직, 투자·금융, 호재. 직원 만족도가 낮으면 노사 갈등이, 경쟁사가 있으면 경쟁사 공세가 잦아집니다.
- **변동 폭**: 회사는 나라보다 빨리 크고 빨리 줄어듭니다. 1년에 직원은 최대 약 90%, 매출은 약 2.6배까지 늘 수 있습니다(국가는 인구 4%, GDP 16%).
- **실존 기업**: 회사와 임원은 모두 가상입니다. 실존 기업과 인물은 시장 환경(경쟁사, 거래처, 정부 정책)으로만 등장하고, Claude가 그들의 발언이나 내부 사정을 지어내지 않도록 규칙에 넣었습니다.

| 연도 | 회사 | 상황 |
| --- | --- | --- |
| 1975 | 동방전자 | 오일쇼크 뒤 수출 드라이브, 라디오·흑백TV 조립 |
| 1997 | 대성섬유 | 외환위기 전야, 고금리와 환율 폭풍 앞의 수출 섬유 회사 |
| 1999 | 누리넷 | 닷컴 붐, 수익 모델 없는 포털 스타트업 |
| 2010 | 별빛게임즈 | 스마트폰 전환기의 피처폰 게임 회사 |
| 2020 | 밀알베이커리 | 팬데믹 직격, 매장 30곳 베이커리 프랜차이즈 |
| 2024 | 한결AI | 생성형 AI 열풍 속 B2B AI 스타트업 |

저장 기록은 게임마다 따로 보관되며, 한쪽 게임의 저장 기록을 다른 쪽에 불러오면 거절합니다.
