# 신화리 온라인 — 기획 문서

> 새 대화에서 작업을 이어갈 때 이 문서를 기준으로 삼는다. 결정이 바뀌면 이 문서부터 고친다.

## 1. 한 줄 정의
충남 논산시 연무읍 신화리를 배경으로 한 **GTA 온라인 스타일의 블랙코미디 오픈월드 온라인 게임**. 스토리 모드 없이 온라인 모드만 있다.

## 2. 플랫폼·기술
| 항목 | 결정 |
|---|---|
| 엔진 | 브라우저 three.js (언리얼 미사용, §12) |
| 플랫폼 | PC 브라우저 (사이트 접속) |
| 그래픽 목표 | 사실적 (구운 조명 + 실사 CC0 에셋, §13) |
| 시점 | **3인칭** (GTA식 어깨 뒤 카메라, 차량은 추적 카메라) |
| 개발 PC | RTX 4070 SUPER |
| 언어 | C++ (+ 필요 시 에디터 Python 스크립트) |
| 멀티플레이 | 방 단위 2~8명, 리슨 서버(방장 PC가 서버). 전용 서버는 이후 소스 빌드로 |
| 작업 방식 | 사용자는 설치·로그인·결제·플레이 피드백만. 나머지는 Claude가 원격으로 진행 |

## 3. 톤·세계관
- **톤:** GTA식 블랙코미디. 풍자 대상은 돈·권력·허세(브로커, 보조금 비리, 투기, 허세 유튜버). 마을 사람과 시골 일상은 애정 있게 그린다.
- **배경:** 딸기와 논산훈련소 면회객으로 먹고사는 마을.
- **플레이어가 마을에 오는 이유:** 오만복 이장의 "신화리 귀농 정착 지원 사업". 귀농인 1명당 보조금이 나오니 사연 있는 사람들을 전국에서 끌어모은다. 지원 물품은 반쯤 무너진 비닐하우스와 낡은 경운기뿐이고 보조금의 행방은 아무도 모른다.
- **대립 구도:** 외지 유통사 "그린밸류 F&B"(딸기 유통 독점, 뒤로는 땅 투기) vs 원주민.
- **실존 지명 사용:** 신화리, 연무읍, 논산훈련소는 실명 사용. 단 **훈련소 내부 배치·경비 체계는 실제와 무관하게 창작**한다. 인물·회사는 모두 가상.

## 4. NPC
| 인물 | 역할 |
|---|---|
| 오만복 이장 | 3선 이장. 보조금 장인. 첫 일거리를 주는 사람. 마을 확성기 방송 담당 |
| 박순례 할머니 | 마을 실세, 딸기 농장주. 마을 편 의뢰인 |
| 최 실장 | 그린밸류 F&B 실장. 양복에 장화. 브로커 편 의뢰인 (보수 큼) |
| 민석 | 귀향민 1기, 망한 "딸기 블록체인" 스타트업 대표. 양쪽에 붙은 이중 스파이. 배신 미션 |
| 김 순경 | 연무 파출소 유일한 순경. 수배 1단계(자전거) |
| 신화슈퍼 사장님 | 정보상. 정보 값은 막걸리 |
| 박 상사(예) | 훈련소 보급관 출신. 충성고물상 운영. 총기 공급처 ("폐기 처분" 고철만 취급) |

## 5. 첫 접속 흐름
1. **입장 화면:** 닉네임만 입력.
2. **마을회관 앞 도착:** 시골 버스에서 내림. 마을회관 앞이 서버 공용 허브.
   - 전입신고 전에는 "미전입자": 하우스 열쇠 없음, 돈벌이 의뢰 불가, 확성기 방송에서 놀림.
3. **마을회관 안 전입신고서 (= 캐릭터 생성):**
   - 성명: 닉네임으로 미리 채워짐 ("이름은 벌써 적어놨어. 동네 소문이 빨라.")
   - 증명사진: 외모 꾸미기
   - 전입 사유: 사업 실패 / 퇴사 / 코인 손실 / 유튜브 각 / 기타 → 시작 빚, NPC 대사가 달라짐
   - 세대 구성: 혼자 또는 친구와 같은 세대 = 크루 (같은 방 입장, 미니맵 표시만. **수익 공유 없음**)
   - 서명: 보조금 특약 동의
4. **정착 지원 물품:** 서류상 300만 원 → 실수령 3만 원("행정 처리비"), 하우스 열쇠, 경운기, 손그림 지도.
5. **확성기 환영 방송.**
6. **이장 전화 → 첫 일거리(튜토리얼).**

## 6. 첫 일거리: "보조금 실사"
이장: "군청에서 보조금 실사 나온대. 30분 뒤에. 니 하우스 딸기가 하나도 없잖여. 순례 할머니네 가서 몇 박스 빌려다 깔아놔."
| 단계 | 내용 | 배우는 것 |
|---|---|---|
| 1 | 마을회관 앞 경운기 타기 (F) | 탑승 |
| 2 | 할머니 하우스로 이동 | 운전, 미니맵 |
| 3 | 할머니에게 딸기 박스 받기 ("이자는 막걸리 두 병") | 대화, 짐 싣기 |
| 4 | 내 하우스로 운반 (시간 제한) | 운전 |
| 5 | 하우스에 박스 배치 | 물건 놓기 |
| 6 | 공무원 차량 도착, 사진 찍고 떠남 | 연출 |
- 선택 체험: 과속·논두렁 질주 시 김 순경 호루라기 (수배 1단계 맛보기).
- 결말: "통과여. 이제 박스 도로 갖다줘." 보상 5만 원, 이장 평판 +1, 휴대폰 연락처에 이장 등록.
- 튜토리얼 중 PvP 피해 없음.

## 7. 온라인 구조
- **서버 1개 = 마을 1개.**
- **핵심 루프:** 돈 벌기 → 장비·탈것·땅 구매 → 더 큰 판.
  - 농사·유통: 수확 → 트럭 운송 → 경매장/직거래
  - 일거리: 택시, 배달, 면회객 수송
  - NPC 의뢰 (휴대폰으로 받음)
  - 범죄: NPC 대상 절도 (§7-1), 경매 조작
- **평판·진영:** 의뢰를 많이 한 쪽으로 마을 편 / 브로커 편 / 양다리.
- **수배:** 1 김 순경(자전거) → 2~3 순찰차 → 4 읍내 기동대 → 5 헌병대(훈련소 근처).
- **정기 이벤트:** 5일장, 입영일(손님 쟁탈 경제전), 수료식(고물상행 납품 트럭 쟁탈 PvP·총기 수급), 이장 선거(시즌, 당선자가 서버 규칙 1개 변경), 딸기축제(시즌 피날레 진영전).
- **협동 작전(헤이스트):** 그린밸류 냉동창고, 경매장 금고, 논산훈련소 외곽 부지 침투(최고 난이도).
- **라디오:** 이장 확성기 방송이 서버 사건을 실시간 방송.
- **무기:** 사실적 GTA 스타일. 실총은 충성고물상·수료식 트럭에서만(희소). 마을 무기(삽, 새총, 개조 분무기, 딸기 박스, 경운기 돌진) 병행.

## 7-1. 절도
**원칙: 플레이어 자산은 털 수 없다.** 절도 대상은 NPC·마을 것뿐. 플레이어끼리는 같은 NPC 표적을 먼저 차지하거나, 훔친 물건을 들고 가는 사람을 들이받아 가로채는 방식으로 경쟁한다. 플레이어 자산 방어 시스템(자물쇠·진돗개·CCTV 설치)은 없다.

| 분류 | 대상 | 포인트 |
|---|---|---|
| 탈것 | NPC 경운기·1톤 트럭·트랙터·냉동탑차, 면회객 렌터카, 이장 SUV, 순찰차, 김 순경 자전거 | 자전거를 뺏기면 김 순경이 걸어서 쫓아옴 |
| 농산물 | NPC 하우스 딸기(밤 서리), 저온저장고, 경매장 출하 트럭 | |
| 농자재·고철 | 비닐 롤, 양수기, 농기계 부품, 전선 | 고물상에서 전부 "고철" 처리 |
| 가축 | 한우 | 소 끌고 가기 미니게임 |
| 빈집 | 입영일에 면회 간 집 | 입영일 이벤트 연동 |
| 공공재산 | 마을회관 금고, 경로당 안마의자 | 금고는 이미 이장이 털어 비어 있음 |
| 택배 | 집 앞 택배 | 내용물은 대부분 홈쇼핑 건강식품 |

**장물 판매처:** 충성고물상(뭐든 싸게), 최 실장(농산물 비싸게, 브로커 평판↑), 읍내 중고차 상사(번호판 교체비), 5일장 좌판(소량, 장날만).

**NPC 방범·추적:** 목격자 할머니 → 신화슈퍼 소문 → 확성기 방송 / 마을 CCTV(절반은 모형) / NPC 집 진돗개(짖으면 주인·이웃 기상) / 신고 시 수배 단계 상승.

**이벤트 연계:** 입영일(빈집), 수료식(납품 트럭), 딸기 출하철(출하 트럭 하이재킹), 협동 작전(냉동창고, 경매장 금고, 한우 농장 "소 떼 대이동").

## 9. 맵
- **기준점:** 신화2리 마을회관 — 충남 논산시 연무읍 동안로576번길 63 (약 36.1350, 127.0687).
- **실제 지형 기반.** 도로·하우스·건물 배치는 위성사진/지도 데이터를 따라간다. 고도는 지형 데이터로.
- **확인된 주변 요소:** 남쪽 마을(파랑·초록 강판 지붕), 둘레 비닐하우스 단지, 북쪽 4차선 동안로(68번), 서쪽 논산천안고속도로, 북동 호남선 철길, 동쪽 저수지, 서쪽 운동장 녹지.
- **창고 단지:** 서쪽 운동장 옆(마을 농가 저온저장고·선별장), 북쪽 동안로 변(그린밸류 창고, 냉동창고 헤이스트 무대).
- **범위 (확정):** 신화리 + 연무읍 + 논산훈련소를 한 맵에. 실제 배치를 압축해 약 1.5~2km. 실제 축척(약 4km)은 쓰지 않음.
- **게임 장소 배정 (미확정):** 신화슈퍼, 할머니 하우스, 내 하우스, 충성고물상 / 연무읍 시내의 파출소, 경매장, 택시 승강장.

## 12. 그래픽 파이프라인 (작업 인계용)
- **방향 확정:** 웹사이트 접속형 우선 + 그래픽 최대한. 언리얼은 쓰지 않음 (사용자 PC 작업 없음).
- **흐름:** Blender 4.2 LTS(헤드리스, 클라우드 컨테이너) → 장면 생성 + Cycles로 조명 굽기(lightmap) → glTF 내보내기 → `blender/postprocess.py`로 웹용 압축 → three.js r160 뷰어(아티팩트).
- **파일:**
  - `blender/build_lookdev.py` — 장면 생성·굽기·내보내기 (`blender -b -P build_lookdev.py -- <tex_dir> <out_dir> <samples> <lm_build> <lm_ground>`, 4096px·48샘플 ≈ 13분)
  - `blender/postprocess.py` — 라이트맵(npy→감마 JPEG, LMAX=4, 행 뒤집기)·텍스처 재압축
  - `blender/hdr_convert.py` — HDRI → .hdr 1K
  - `lookdev2/index.html` — 뷰어 (importmap으로 three 0.160.0 모듈, OrbitControls, GTAO·Bloom·색보정)
- **아티팩트 제약 (중요):** `.bin/.glb/.hdr/.gltf` 확장자는 서빙 안 됨, `data:` URL fetch는 CSP로 차단됨.
  → glTF JSON은 `scene.json`(버퍼 uri 제거), 버퍼는 `scene_bin.json`(base64) → 브라우저에서 GLB로 조립해 `GLTFLoader.parseAsync`. HDR은 `sky_env.json`(base64) → `RGBELoader.parse`.
  → 로컬 테스트 서버에 CSP 헤더(`connect-src 'self'`)를 걸고 확인할 것.
- **라이트맵 수식:** three 확산 = albedo/π × lightMap × intensity → `lightMapIntensity = LMAX·π`, lightMap `channel=1`, `flipY=false`, sRGB.
- **에셋:** ambientCG(CC0) 텍스처 1K, HDRI DaySkyHDRI069A. 폰트 Black Han Sans / IBM Plex Sans KR(간판 PNG용).
- **게시된 테스트:** v1 https://claude.ai/artifact/Dtc9xRUxhxWDkZ2yM8usPA (절차적), v2 https://claude.ai/artifact/SXaGYoKkrWvtUiWg1SAP6e (구운 조명)
