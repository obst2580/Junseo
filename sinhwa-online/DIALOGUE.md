# GTK 대사 목록

대사는 사용자가 직접 쓴다. 게임에 들어간 대사는 전부 `game_pub/lines.json`에 상황별로 있다.

- **상황 키**: 코드가 부르는 이름이다. 바꾸지 않는다.
- **`lines`**: 대사를 넣는 곳이다.
  - `"*"`는 기본 대사이고, 사람 id 키는 그 사람만 쓰는 대사다.
  - 사람 id: `minseok`, `halmeoni`, `ijang`, `syuper`, `anjun`, `woochan`, `jinwook`, `parkjin`, `police`
  - 스토리 없는 오픈월드라 행인은 위 사람들의 모델을 복제해서 거리를 걷는다. 행인 대사는 `"*"`에 넣으면 된다.
- **형식**: `"대사"`처럼 문자열로 쓰거나, 음성이 있으면 `{"text": "대사", "voice": "voice/파일.mp3"}`로 쓴다.
- **표시**: 화면 하단 중앙에 자막으로 나온다. 26m 안에서 한 말만 보인다. 음성이 있으면 자막이 그 길이만큼 유지된다.

새 기능을 만들다가 대사가 필요한 곳이 생기면 아래 **대기 목록**에 적어 둔다. 대사를 받으면 `lines.json`에 넣고 표로 옮긴다.

## 1. 게임에 연결된 상황 (`lines.json`)

| 키 | 언제 | 누가 |
|---|---|---|
| `hit_fight` | 싸우는 주민이 처음 맞았을 때 | 안준·조우찬·홍진욱·박진·슈퍼 사장님 |
| `hit_flee` | 겁 많은 주민이 맞고 도망칠 때. 할머니·이장님은 전용 대사 | 할머니·이장님 |
| `gang_join` | 4인방 중 한 명이 맞으면 근처의 나머지가 합세할 때 | 4인방 |
| `ko` | 체력이 바닥나 기절할 때 | 주민·경찰 |
| `fight_over` | 싸움이 끝나고 돌아설 때 | 싸우던 주민 |
| `cop_spot` | 출동한 경찰이 민석을 처음 봤을 때 | 경찰 |
| `cop_hit` | 경찰이 맞았을 때(40% 확률) | 경찰 |
| `cop_lost` | 수배가 풀려 철수할 때 | 경찰 |
| `cop_arrest` | 쓰러진 민석을 체포할 때 | 경찰 |

## 2. 대기 목록: 대사가 필요한데 아직 게임에 없는 요소

이 상황들은 대사를 받으면 바로 연결한다.

| 제안 키 | 언제 | 누가 | 메모 |
|---|---|---|---|
| `player_taunt` | 민석이 싸움을 걸 때, 콤보 중 | 민석 | 지금 민석은 말을 안 함 |
| `player_hurt` | 민석이 세게 맞았을 때 | 민석 | |
| `player_ko` | 민석이 기절할 때 | 민석 | "기절!" 화면과 함께 |
| `player_busted` | 민석이 체포될 때 | 민석 | 변명·항변 |
| `release` | 지구대 훈방 후 풀려날 때 | 경찰(지구대) | 지금은 시스템 문구 "연무지구대 훈방 조치. 이번만 봐준다." |
| `radio_dispatch` | 수배 별이 처음 붙어 출동할 때 | 무전(목소리만) | 예: 신고 접수 무전 |
| `radio_backup` | 별 3개 이상, 지원 병력 출동 | 무전 | |
| `exec_line` | 처형 컷씬의 마지막 한 방 직전 | 민석 | 처형 기술 3종(원투 어퍼 피니시, 무릎 옆차기 처형, 날아차기 피날레)별로 따로 받아도 됨 |
| `exec_victim` | 처형당해 죽기 직전 마지막 말 | 피해자 | 처형은 죽음으로 끝남(일어나지 않음). 마지막 한 방 직전이나 쓰러지며 |
| `idle_chatter` | 평소 혼잣말 / 지나가며 한마디 | 모든 주민 | 사람별로 받으면 좋음 |
| `greet` | 민석이 가까이 다가왔을 때 | 모든 주민 | 수배 중이면 다른 반응 |
| `getup` | 기절했다 일어날 때 | 주민·경찰 | |
| `witness_body` | 시체를 발견했을 때 | 주민 | 처형으로 죽은 사람은 90초 뒤, 30m 밖에 있을 때 치워지고 집에서 다시 나타남 |
| `mug_give` | 위협당한 행인이 손을 들고 지갑을 내줄 때 | 행인 | E(돈 내놔)로 위협 성공. 무기가 셀수록 잘 내줌 |
| `mug_refuse` | 위협을 거부할 때(맞서거나 도망) | 행인 | 맨손이면 거친 사람은 덤빔 |
| `mug_call` | 도망친 뒤 경찰에 신고 전화를 걸 때 | 행인 | 전화 동작 3초 뒤 수배 ★1. 그 전에 쓰러뜨리면 신고 안 됨 |
| `panic` | 총소리를 듣고 도망칠 때 | 행인 | 비명·외침 |
| `jack_victim` | 차를 뺏기고 운전석에서 끌려 나올 때 | 운전자(행인) | F로 차량 강탈. 3초 뒤 신고 전화 |

## 3. 앞으로 생길 대사

- 스토리 없이 오픈월드로 간다. 강도 요소(가게 털기, ATM·금고, 차량 강탈)를 만들 때 필요한 대사를 위 대기 목록에 추가한다.
