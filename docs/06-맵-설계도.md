# 도시 설계도 v1 — 스케치를 실제 좌표로

> 운영자 손그림 스케치(2026-10-04)를 따라 그려서 **블록 좌표**로 옮긴 초안입니다. 1블록 = 1m입니다.
> 앞으로 지형 생성, 건축, 플러그인 설정(장소 등록)의 기준이 됩니다.
>
> **파일**
> - 데이터(기준 원본): [`map/layout.json`](../map/layout.json)
> - 그림 만들기: `python3 map/render_layout.py map/layout.json docs/images/map-v1.svg`
>
> **표기**
> - **[확정]** 운영자가 정한 것
> - **[제안]** 초안이며 바꿀 수 있는 것
> - **[확인 필요]** 스케치만으로는 알 수 없어서 제가 정한 것

## 5. 도로

| 종류 | 도로 | 경로 |
|---|---|---|
| 고속도로 (빨강) | 공항고속도로 | 공항 → 청라 → 구인천 → 한강 교량 → 마포 |
| | 강변북로·북부순환 | 마포 → 홍대 남쪽 강변 → 중구를 감싸고 → 광진 |
| | 용산 강변로 | 홍대 남쪽 → 용산·남산 강변 → 광진 |
| | 남부순환·올림픽대로 | 공항 → 구인천·대형시장·대학교 남쪽 → 강남 → 송파 → 한강 교량 → 광진 |
| 대로 (주황) | 북부 대로 | 북한산과 홍대·중구 사이 |
| | 홍대 대로, 마포 대로 | 각 구역을 남북으로 |
| | 중구·강남 대로 | 북한산 → 중구 → **남산터널** → 한남대교 자리 → 강남대로 |
| | 남부 대로 | 대형시장 → 대학교 → 강남 → 송파 |
| | 구인천 대로 | 청라 → 구인천 → 대형시장 |
| 한강 다리 (노랑) | 마포대교 | 홍대 ↔ 여의도 |
| | 서쪽 연결교 | 구인천 ↔ 여의도 |
| | 원효대교 자리 | 여의도 ↔ 용산 |
| | 샛강다리 | 여의도 ↔ 대형시장 |
| | 한남대교 자리 | 남산 ↔ 강남 |

- **여의도 안 도로 [제안]:** 다리를 잇는 길이 없어서 추가했습니다.
  - 여의대로: 동서 방향
  - 마포대교 연결로, 샛강다리 연결로
- **공항 활주로:** 고속도로와 겹치지 않게 공항 북서쪽에 두었습니다. 길이 1.3km입니다.
- 중로(회색)는 구역을 지을 때 구역 안에서 정합니다.
- 차로 폭은 기획서 6.4를 따릅니다. 1차로 4블록, 고속도로 왕복 6차로입니다.

## 6. 높이 [제안]
마인크래프트 월드의 높이는 Y −64부터 320까지 384블록입니다.

**방법: 땅 높이를 낮게 잡습니다**

| 항목 | 높이 |
|---|---|
| 땅 | Y 0 |
| 한강·바다 수면 | Y −1 |
| 지하 공간 | Y −64~0 (지하철, 지하주차장, 하수도 은신처) |
| 남산 정상 | Y 260 (실제 262m와 거의 같음) |
| 북한산 정상 | Y 300 (실제 836m에서 줄임) |
| 초고층 타워 | Y 320까지, 약 320m (실제 555m에서 줄임) |

- 보통 월드처럼 땅을 Y 64에 두면 위로 256m밖에 남지 않습니다. 그러면 남산도 실제보다 낮아지고 타워도 짧아집니다.
- 땅을 Y 0으로 내리면 구름(Y 192)도 땅에서 약 190m 위에 떠서 도시 높이감이 자연스럽습니다.
- 우리가 만드는 생성기(7장)로 월드를 만들기 때문에 땅 높이를 자유롭게 정할 수 있습니다.

## 7. 바탕 월드 만들기
기획서 6.7의 순서를 이 설계도에 맞춰 구체화했습니다.

> **바탕 생성기를 만들었습니다** (2026-10-05).
> - 사용법은 [`mapgen/README.md`](../mapgen/README.md)를 보세요.
> - 아래 그림은 생성기가 만들 지형을 위에서 내려다본 미리보기입니다. 서버 없이 지형 계산만으로 그렸습니다.
>
> ![생성 미리보기](images/mapgen-map-preview.png)
>
> 확대(1px = 1블록): [여의도](images/mapgen-yeouido-1to1.png), [남산터널](images/mapgen-namsan-tunnel-1to1.png)

1. **설계도 확정:** 이 문서와 그림을 보고 위치를 고칩니다. 지금 단계입니다.
2. **바탕 월드 자동 생성:** 「도시 바탕 생성기」를 만듭니다. ✅ 생성기 완성
   - `layout.json`을 읽어서 Paper 월드 생성기(ChunkGenerator)로 아래를 자동으로 만듭니다.
     - 땅, 한강, 바다, 섬
     - 남산·북한산 지형
     - 도로: 아스팔트, 차선, 인도
     - 다리와 터널 자리
     - 구역마다 색을 달리한 바닥
   - 건축 서버(Paper)에서 Chunky로 미리 생성합니다. 10×5.6km라서 디스크 몇 GB 수준입니다 [추론].
3. **구역 채우기:** 구역마다 아래 둘 중에서 고릅니다.
   - 직접 짓기
   - 실제 동네를 Arnis로 생성해서 잘라 붙이기
4. **랜드마크 짓기:** 남산타워, 금융 타워, 방송국, 공항 터미널, 돔구장, 초고층 타워, 교도소 등
5. **운영 서버로 옮기기:** 완성되면 Folia 운영 서버로 복사합니다. 1차 오픈 구역부터 엽니다.
