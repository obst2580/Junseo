# 도시 설계도 v2 — 4.5×2.5km, 공항은 섬

> 운영자 손그림 스케치(2026-10-04)를 블록 좌표로 옮긴 설계도입니다. 1블록 = 1m입니다.
>
> **v2 (2026-10-05) 변경 [확정]**
> - **절반 크기(약 4.5×2.5km)로 줄였습니다.** 처음 크기(9×5km)가 너무 컸기 때문입니다.
> - **공항을 섬으로 떼어 냈습니다** (영종도처럼). 해협 위로 고속도로 다리 2개가 건너갑니다.
>
> **파일**
> - 데이터(기준 원본): [`map/layout.json`](../map/layout.json)
> - 그림 만들기: `python3 map/render_layout.py map/layout.json docs/images/map-v1.svg`
>
> **표기**
> - **[확정]** 운영자가 정한 것
> - **[제안]** 초안이며 바꿀 수 있는 것

## 5. 도로

| 종류 | 도로 | 경로 |
|---|---|---|
| 고속도로 (빨강) | 공항고속도로 | 공항 → **해협 대교** → 청라 → 구인천 → 한강 교량 → 마포 |
| | 강변북로·북부순환 | 마포 → 홍대 남쪽 강변 → 중구를 감싸고 → 광진 |
| | 용산 강변로 | 홍대 남쪽 → 용산·남산 강변 → 광진 |
| | 남부순환·올림픽대로 | 공항 → **해협 대교** → 구인천·대형시장·대학교 남쪽 → 강남 → 송파 → 한강 교량 → 광진 |
| 대로 (주황) | 북부 대로 | 북한산과 홍대·중구 사이 |
| | 홍대 대로, 마포 대로 | 각 구역을 남북으로 |
| | 중구·강남 대로 | 중구 → **남산터널** → 한남대교 자리 → 강남대로 |
| | 남부 대로 | 대형시장 → 대학교 → 강남 → 송파 |
| | 구인천 대로 | 청라 → 구인천 → 대형시장 |
| | 여의도 도로 [제안] | 여의대로(동서), 마포대교 연결로, 샛강다리 연결로 |
| 한강 다리 (노랑) | 마포대교 | 홍대 ↔ 여의도 |
| | 서쪽 연결교 | 구인천 ↔ 여의도 |
| | 원효대교 자리 | 여의도 ↔ 용산 |
| | 샛강다리 | 여의도 ↔ 대형시장 |
| | 한남대교 자리 | 남산 ↔ 강남 |
| 바다 다리 | 해협 대교 2개 | 공항 섬 ↔ 청라 (고속도로) |
| 공항 활주로 | 650m | 공항 섬 북서쪽 |

- 도로 폭은 실제 크기 그대로입니다. 1차로 4블록, 고속도로 28블록, 대로 24블록(인도 포함).
- 중로(회색)는 구역을 지을 때 구역 안에서 정합니다.

## 7. 바탕 월드 만들기
**도시 바탕 생성기(`JunseoMapGen`)**가 이 설계도로 땅, 한강, 바다, 산, 도로, 다리, 터널을 자동으로 깝니다. 사용법은 [`mapgen/README.md`](../mapgen/README.md)를 보세요.

![생성 미리보기](images/mapgen-map-preview.png)

확대 그림(1px = 1블록): [여의도](images/mapgen-yeouido-1to1.png), [남산터널](images/mapgen-namsan-tunnel-1to1.png), [공항 섬](images/mapgen-airport-1to1.png)

**순서**
1. 설계도 확정 ✅
2. 바탕 월드 자동 생성 ✅ (생성기 완성)
3. **구역 채우기:** 구역마다 아래 둘 중에서 고릅니다.
   - 직접 짓기
   - 실제 동네를 Arnis로 생성해서 잘라 붙이기
4. **랜드마크 짓기:** 남산타워, 금융 타워, 방송국, 공항 터미널, 돔구장, 초고층 타워, 교도소 등
5. **운영 서버로 옮기기:** 완성되면 Folia 운영 서버로 복사합니다. 1차 오픈 구역부터 엽니다.
