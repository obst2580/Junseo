## 1. 인생모드의 본질 (한 줄 요약 7개)

1. **주인공은 시스템이 아니라 사람입니다.** 경찰·의사·정비사·기자·갱을 모두 플레이어가 맡습니다. 게임은 무대와 도구만 줍니다. [요약]
2. **이야기는 정해져 있지 않고 저절로 생깁니다.** 아래 사건은 모두 시스템과 사람이 부딪쳐서 생긴 이야기입니다. [요약]
   - 봉누도의 「대기근」: 배고픔 시스템 → 식량 위기 → 식당·경찰·갱의 협력
   - 「사과박스 뇌물 폭로전」, 경찰 쿠데타, 시장 선거
3. **목소리로 대화합니다.** 가까운 사람에게만 들리는 근접 음성이 기본이라 마이크가 사실상 필수입니다. [요약]
   - FiveM 표준 음성(pma-voice) 범위: 속삭임 3m / 보통 7m / 외침 15m [원문]
4. **규칙도 게임의 일부입니다.** 캐릭터 연기(IC)를 유지해야 하고, 아래 행동을 금지합니다. [요약·원문]
   - 메타게이밍: 방송이나 디스코드에서 본 정보를 쓰는 것
   - RDM / VDM: 이유 없는 살인 / 차로 들이받기
   - 현실적이지 않은 행동
   - 위반은 관리자가 판정합니다.
5. **경제가 사람을 움직입니다.** 월급, 알바, 사업, 범죄 수익, 세금, 벌금, 병원비가 서로 맞물려 돌고, 돈이 직업 선택과 범죄 동기가 됩니다. [원문·요약]
6. **범죄와 경찰은 한 세트입니다.** 강도는 **근무 중인 경찰이 일정 수 이상일 때만** 시작할 수 있습니다. 경찰이 없으면 범죄 콘텐츠도 없습니다. [원문]
7. **죽음은 끝이 아니라 장면입니다.** 맞으면 바로 죽지 않고 **쓰러지고**, 누군가 구하러 오는 동안 이야기가 이어집니다. 끝내 못 살아나면 병원에서 깨어나고 비용을 냅니다. [원문]

## 2. 플레이어가 실제로 겪는 장면 (흐름)

### 장면 ① 뉴비의 첫날
1. **입국:** 서버 디스코드에서 인증하고 규칙(「법률」)을 읽습니다.
   - 리얼월드 예: 게임 안 마커에서 「인증코드 받기」 → 디스코드 「뉴비인증」 채널에 코드 입력 → 게임 안 「지원받기」 [원문]
   - 해외 하드 RP 서버는 신청서와 면접으로 받습니다. [요약]
2. **캐릭터 생성:** 이름, 생년월일, 외형을 정합니다. QBCore는 계정당 캐릭터 슬롯 5개입니다. [원문]
3. **지원품 받기:** 휴대폰, 신분증, 정착금, 뉴비 상자를 받습니다.
   - 리얼월드: 뉴비 상자 + 휴대폰 + 일정 시간 뒤 자동 반납되는 **뉴비 렌트카** [원문]
   - 다른 서버: 정착금 2~4억(게임 머니) [요약]
4. **첫 돈벌이:** 낚시, 막노동, 배달, 채광, 농사, 벌목 같은 **시민 알바**로 시작합니다.
   - 경찰, 의사, 갱은 뉴비에게 비추천입니다. [요약]
5. **적응:** 폰 사용법, 음식·물 사기, 택시·정비 부르기, 사람들과 대화하며 인맥 만들기를 익힙니다. [추론]
6. **이탈 위험:** 기존 유저끼리만 놀아서 낄 자리가 없으면 떠납니다.
   - 대응: 뉴비보호법, 뉴비 도우미 직업(「뉴비유치원」), 정착금 [요약]

### 장면 ② 경찰의 근무 하루 (사람이 하는 경찰)
1. **출근(근무 시작):** 경찰서에서 출근 버튼을 누릅니다.
   - 근무 중인 경찰 수가 서버 전체에 집계되고, 범죄 콘텐츠의 시작 조건이 됩니다.
   - 근무 중인 경찰·의료국은 지도에서 서로 보입니다. [원문]
2. **장비:** 계급별로 무기고·차량 권한이 다릅니다. 수갑, 손전등, 증거봉투, 방탄복을 챙깁니다. [원문]
3. **신고 받기:** 디스패치 화면에 신고가 뜹니다.
   - 시민의 112 신고(폰)와 자동 신고(총소리, 차량 절도, 강도, 사람 쓰러짐)가 함께 들어옵니다.
   - 대략적 위치는 원으로 표시되고, 받은 경찰이 「응답」을 누르면 출동입니다. [원문]
4. **현장 대응:**
   - 체포: 수갑 → 연행(끌고 가기) → 차에 태우기 [원문]
   - 수색: 상대가 수갑을 찼거나, 쓰러졌거나, 손을 든 상태일 때만 가능합니다. [원문]
   - 압수: 검은돈, 마약, 불법 무기
   - 신원 확인: 신분증·면허 확인, 지문·DNA·탄피·혈흔 같은 증거 수집 [원문]
5. **처분 (보통 경찰이 고릅니다):**
   - **벌금:** 범죄별 벌금표가 있고, 청구서로 발부합니다. 잔액이 부족하면 미납 청구서로 남습니다. [원문]
     - 리얼월드 예: 폭행 100만, 차량절도 200만, 공무집행방해 300만 [원문]
   - **감옥:** 형량을 정해 수감합니다.
     - QBCore: 1개월 = 실제 1분 [원문]
     - 수감되면 소지품을 보관하고 죄수복으로 갈아입으며, 교도소 작업이 있습니다.
   - **압류:** 차량을 견인소로 보내고, 찾을 때 비용을 받습니다. [원문]
6. **기록:** MDT(경찰 전산)에 시민 기록, 사건 보고서, 영장, 수배(BOLO)를 남깁니다. 보고서 작성이 의무인 서버도 있습니다. [원문·요약]
7. **조직:** 계급(순경 → … → 청장)이 있고, 보스(청장)가 고용·승진·해고·월급을 관리합니다. [원문]
8. **퇴근:** 퇴근하면 호출을 받지 않고 장비도 쓰지 않습니다. 월급은 근무 중에만 나오는 것이 기본입니다. [원문]

### 장면 ③ 편의점·은행 강도
1. **조건 확인:** 근무 중인 경찰이 N명 이상이어야 합니다.
   - QBCore 기본: 편의점·보석상 2명
   - 리얼월드 은행: 5명
   - 요양타운 편의점: 3명 [원문·요약]
2. **도구:** 락픽, 해킹 키트, 써마이트 같은 준비물이 필요하고, 미니게임(스킬체크)을 거칩니다. [원문]
3. **경보:** 시작과 동시에 경찰 디스패치에 「강도 발생」이 뜨고 경보가 울립니다. [원문]
4. **진행:** 금고를 열거나 진열장을 깨는 데 시간이 걸리고, 그동안 경찰이 도착합니다. [원문]
5. **결말:** 결말은 시스템이 아니라 사람끼리 정해집니다.
   - 도주 성공: 경찰 시야를 벗어나면 승리
   - 체포: 감옥
   - 교전: 쓰러짐 → 의료국 [요약]
6. **장물과 검은돈:** 보상은 금괴·롤렉스 같은 장물이나 **검은돈**입니다. 그대로는 못 쓰고 **세탁**(수수료 약 25%)해야 합니다. [원문]
7. **밸런스 조정:** 서버들은 경찰 대 범죄자 비율, 쿨타임(10분~1시간)을 계속 조정합니다.
   - 요양타운: 편의점 강도 인원 3명 → 4명, 경찰 대 범죄자 9:7 → 11:7 [요약]

### 장면 ④ 총에 맞고 쓰러짐 → 의료국
1. **쓰러짐:** 체력이 0이 되면 바로 죽지 않고 **쓰러진 상태(다운)**가 됩니다. 싸울 수 없고 바닥에서 버둥거립니다. [원문]
   - QBCore: 출혈 타이머 6분(360초)
   - 봉누도 2: 5분 뒤 「포기」 가능, 15분 뒤 자동 병원 리스폰 [요약]
2. **구조 요청:** 쓰러진 상태에서 **키 한 번(G)으로 의료국 호출**이 갑니다. 쓰러진 사람은 디스패치에 자동 신고되기도 합니다. [원문]
3. **구조:**
   - 의료국이 와서 진행바 동안 치료·소생합니다.
   - 일반인도 응급키트가 있으면 살릴 수 있습니다(QBCore). [원문]
   - 비용(예: 소생 50만, 치료 30만)은 의료국 회사 수입이 됩니다. [원문·요약]
4. **못 살아나면:** 병원에서 리스폰하고 병원비를 냅니다. [원문]
   - QBCore: $2,000, 소지품 압수 옵션
   - 의료국이 2명 미만이면 병원 셀프 체크인(AI 치료)이 열립니다.
5. **뉴라이프 규칙(NLR):** 리스폰한 뒤에는 죽기 전 사건을 「잊어야」 합니다. [요약]
6. **의료국의 위치:** 중립 직업이라 공격하면 무거운 처벌을 받는 서버가 많습니다.
   - 반대로 「소생 기계」처럼 소비되면 재미가 떨어집니다. 그래서 자동 리스폰을 섞습니다. [요약]

### 장면 ⑤ 직장과 사업
1. **지원:**
   - 공무직(경찰, 의료국, 기자)은 지원서와 면접으로 뽑습니다.
   - 일반 직업은 시청 「잡센터」에서 바로 시작합니다. [원문·요약]
2. **고용:** 회사의 보스가 근처 플레이어를 **고용**하고 승진·강등·해고합니다. 등급별 월급도 보스가 정합니다. [원문]
3. **회사 계좌:** 청구서 수입, 병원비, 차량 판매 수익이 회사 계좌로 들어오고, 보스가 급여와 장비비로 씁니다. [원문]
4. **플레이어 사업체:** 식당, 정비소, 클럽, 중고차 매매처럼 플레이어가 운영하는 가게가 있습니다.
   - 서비스 요금은 **청구서**로 받습니다(예: 정비 수수료 10%). [원문]
   - 봉누도 2는 **평판이 높아야** 개인 사업체를 차릴 수 있었습니다. [요약]
5. **정치와 언론:** 시장 선거(세금·공권력 권한), 기자(기사로 평판이 바뀜)가 있는 서버도 있습니다. [요약]

### 장면 ⑥ 일상
- **배고픔·목마름:** 시간이 지나면 줄고, 0이 되면 체력이 닳습니다.
  - QBCore: 약 2시간에 바닥
  - 리얼월드: 분당 0.5씩 감소 [원문]
  - 음식은 상점이나 **플레이어 식당**에서 사므로 식당 직업의 수요가 생깁니다.
- **스트레스:** 총 쏘기, 과속, 범죄로 쌓입니다. 높으면 화면이 흔들리고, 반복 노동을 제한하는 용도로도 씁니다. [원문·요약]
- **휴대폰:** 아이템이라서 뺏기면 연락 수단을 잃습니다.
  - 앱: 전화, 문자, 연락처, 은행(송금·청구서 납부), SNS(트위터형), 광고판, 차고(내 차 위치), 서비스(근무 중인 경찰·의료국·정비·택시·변호사에게 바로 연락), 사진
  - 경찰에게는 MDT 앱이 있습니다. [원문]
- **무전기:** 주파수 채널로 통화합니다. 1~10번은 근무 중인 경찰·의료국 전용입니다(QBCore). [원문]
- **자동차:**
  - 기본: 차량은 열쇠가 있어야 시동을 겁니다. 연료가 줄고, 손상되면 수리해야 합니다.
  - 보관: 차고에 넣고 빼며, 서버가 재시작하면 차고로 돌아갑니다.
  - 절도: 남의 차는 락픽이나 핫와이어(성공률 50%, 경보)로 훔칩니다. [원문]
  - 경찰 대응: 신고 확률이 있고, 견인소 압류가 있습니다.
- **집:** 구매·임대, 가구 배치, 보관함, 옷장, 열쇠 공유, 개인 차고가 있습니다. 경찰이 압수수색할 수 있습니다. [원문]
- **면허:** 운전면허, 무기면허가 있고 시청에서 발급합니다. 면허가 없으면 무기점을 쓸 수 없고, 경찰(등급 2 이상)이 취소할 수 있습니다. [원문]

## 3. 핵심 규칙과 수치 (설계 기준값)

| 항목 | 대표 기본값 | 근거 |
|---|---|---|
| 월급 주기 | QBCore 10분, ESX 7분, 리얼월드 30분 (근무 중일 때만, 소득세 8%) | [원문] |
| 시작 자금 | QBCore 현금 500 + 은행 5,000 | [원문] |
| 돈의 종류 | 현금 / 은행 / **검은돈**(압수 대상, 세탁 필요) | [원문] |
| 강도 최소 경찰 | 편의점·보석상 2명, 은행 3~6명 (서버마다 조정) | [원문·요약] |
| 강도 쿨타임 | 편의점 30분, 보석상 60분 | [원문] |
| 세탁 수수료 | 약 25% | [원문] |
| 쓰러짐 → 사망 | 6분 출혈 → 사망 → 5분 뒤 리스폰 가능 | [원문] |

## 4. 사람 사이의 규칙 (운영 규칙)

시스템으로 막을 수 없어서 **사람(관리자)이 판정하는** 규칙입니다.

| 용어 | 뜻 |
|---|---|
| IC / OOC | IC는 캐릭터로서의 말과 행동, OOC는 플레이어 본인으로서의 말과 행동 |
| 메타게이밍 | 캐릭터가 알 수 없는 정보(디스코드, 방송, 현실 친분)를 쓰는 것 |
| 파워게이밍 | 현실적으로 불가능한 행동. 예: 총 맞고 멀쩡히 뛰기 |
| Non-RP / Bad-RP | 역할극을 깨거나 몰입을 해치는 행동 |
| RDM / VDM | 이유 없이 죽이기 / 차로 치기 |
| 공포 RP | 총이 겨눠지면 목숨을 아끼는 반응을 해야 함 |
| 뉴라이프(NLR) | 죽었다 깨어나면 그 사건을 잊음 |
| 콤뱃로그 | 불리할 때 접속을 끊고 도망가기 |

- **처벌:** 경고 → 관리자 감옥 → 기간 정지 → 영구 밴 [요약·원문]
- **처벌을 RP로 녹이는 방식도 있습니다.** 예: 봉누도는 현실을 언급하면 「정신병원 입원」으로 처리했습니다. [요약]
- **신고·판정 체계가 필요합니다.** 폰에서 관리자를 호출하는 기능과 로그가 있어야 합니다. [요약·추론]

## 5. 잘 되는 서버와 망하는 서버

| 뉴비 이탈 | 고인물 카르텔 | 정착금, 뉴비 도우미, 뉴비 보호 |
| 경찰 권력 남용 | 마구잡이 체포·테이저 | 체포·벌금 로그, 사유 기록, 상한선 |

## 6. 마인크래프트로 옮기기: 대응표

UI 원칙 (사용자 요청):
- **명령어(/) 대신 스마트폰 메뉴로 통합합니다.**
- **전부 클릭으로 처리하고 입력창은 쓰지 않습니다.**
- **경찰·의료국은 사람이 맡습니다(AI 경찰 없음).**

### 6.1 조작 방식

| FiveM | 마인크래프트 | 근거·비고 |
|---|---|---|
| 휴대폰 (M/F1 키) | **G 키 = 스마트폰.** 바닐라에 「빠른 동작」 키(기본 G)가 있고, 서버가 지정한 메뉴가 열립니다. 폰 아이템 우클릭으로도 열 수 있습니다. | [원문] 26.3 클라이언트 코드, Paper Dialog API |
| 3rd-eye (Alt로 사람·물체 조준 → 옵션) | **사람·물체를 보고 우클릭** → 그 대상에 맞는 버튼 메뉴. 예: 사람을 보면 신분증 보기 / 돈 주기 / (경찰) 수갑·수색·벌금 / (의료국) 치료 | [추론] Paper 상호작용 이벤트로 구현 가능 |
| 라디얼 메뉴 / 컨텍스트 메뉴 | 대화창(Dialog)의 **버튼 격자**(열 수 지정 가능) | [원문] Paper API `MultiActionType.columns` |
| 입력 다이얼로그 (금액·형량) | **버튼만 사용.** 금액은 [+1만][+10만][-1만] → [확인], 형량은 [1분][3분][5분] | 사용자 요청 |
| 진행바 / 스킬체크 | 보스바·액션바 진행도 + "움직이면 취소" | [추론] |
| HUD | 사이드바·액션바 (리소스팩을 쓰면 아이콘 HUD) | [원문] |

### 6.2 시스템 대응

| 인생모드 시스템 | 마인크래프트 구현 | 모드 필요? |
|---|---|---|
| 근접 음성 / 전화 / 무전 | Simple Voice Chat. 서버 플러그인 + **플레이어 모드 필요.** 통화와 무전 채널은 그 API로 구현 | **클라이언트 모드 필요** |
| 휴대폰 앱 (은행, 문자, 연락처, 서비스 호출, SNS, 광고, 차고, MDT) | 대화창 앱. 문자는 정해진 문장 버튼으로 | 불필요 |
| 직업·계급·출퇴근·월급·보스 메뉴 | 플러그인 직접 구현 | 불필요 |
| 경찰: 디스패치·수갑·연행·수색·압수·벌금 청구서·감옥·MDT 기록 | 직접 구현 (기존 경찰 플러그인은 최신 버전 미지원) | 불필요 |
| 쓰러짐 → 의료국 호출 → 소생 / 병원 리스폰 | 체력 0을 취소하고 기어가는 자세, 타이머, 소생 진행바 | 불필요 |
| 현금 / 은행 / 검은돈, 청구서, 회사 계좌, 세탁 | 직접 구현 | 불필요 |

| 인벤토리 무게 | 바닐라 인벤토리 사용 (무게 시스템 생략) | — |

### 6.3 현재 v0.1에서 바뀌어야 할 것
- **AI 경찰 삭제.** 수배는 「AI 출동」이 아니라 **경찰 디스패치 신고 + 경찰 MDT 기록**으로 바꿉니다.
- **명령어를 폰 앱과 상호작용 메뉴로 이전**합니다. 관리자 명령어만 남깁니다.
- **즉사를 쓰러짐(다운)으로 바꿉니다.** 의료국 호출 → 소생 / 병원 리스폰 + 병원비.
- **의료국 직업을 추가**합니다. 출퇴근, 계급, 회사 계좌, 보스 메뉴도 만듭니다.
- **강도를 근무 중 경찰 N명 이상으로 묶고**, 보상은 **검은돈 → 세탁**으로 바꿉니다.
- **벌금을 범죄별 벌금표 + 청구서**로 바꿉니다.
