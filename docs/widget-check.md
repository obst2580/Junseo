# 위젯 실기기 점검표

위젯은 이 앱의 핵심인데, 아이폰 홈 화면에서만 동작해서 웹 미리보기로는 확인할 수 없다.
컴파일은 GitHub Actions 의 Mac 에서 매번 확인한다 (`.github/workflows/ios.yml`). 이 문서는 그다음, **실제 아이폰에서** 볼 것들이다.

## 준비

| 항목 | 내용 |
|---|---|
| 폰 | iOS 17 이상 아이폰 1대 (iOS 26 이면 위젯 푸시까지 확인된다) |
| 친구 역할 | 두 번째 폰, 또는 PC 의 웹 미리보기 (`npx expo start --web`) 에서 친구 계정으로 로그인 |
| 서버 | 폰이 닿는 주소 (`EXPO_PUBLIC_API_URL=http://<PC의 LAN IP>:8080`), APNs 키 (`JUNSEO_APNS_*`) |
| 앱 | 개발 빌드 (`npx expo run:ios --device`, Mac 이 없으면 `npx eas-cli build --profile development --platform ios`) |
| 시간 재기 | 서버 로그의 `Widget got new photo` 줄 (아래) |

## 걸린 시간 재는 법

위젯이나 알림 확장이 **새 사진을 처음 받아 갈 때** 서버가 한 줄 남긴다.

```
Widget got new photo: user=5 moment=14 source=notification after=2380ms
```

- `after` — 친구가 사진을 올린 뒤 이 폰이 받아 가기까지 걸린 시간
- `source` — 받아 간 경로. `notification` 은 사진 알림(알림 서비스 확장), `widget` 은 위젯 스스로(위젯 푸시 · 15분 예약 · 앱이 요청)
- 같은 사진에 댓글·반응만 바뀐 갱신은 남기지 않는다

`grep "Widget got new photo" <서버 로그>` 로 모아 보면 된다. 사진이 실제로 화면에 바뀌는 건 이보다 조금(보통 1초 안쪽) 뒤다.

## 점검 항목

### 1. 기본

- [ ] 로그인 전: 위젯에 「앱에서 로그인해 주세요」
- [ ] 로그인 후, 받은 사진이 없으면: 「친구가 사진을 보내면 여기에 떠요」
- [ ] 작은 위젯 · 큰 위젯 둘 다 추가된다 (위젯 고르는 화면 설명: 「친구가 보낸 최신 사진과 댓글을 보여줘요.」)
- [ ] 위젯을 누르면 그 사진의 상세 화면이 열린다
- [ ] 로그아웃하면 위젯이 「앱에서 로그인해 주세요」로 돌아간다

### 2. 새 사진이 뜨기까지 (가장 중요)

친구가 사진을 보낼 때마다 서버 로그의 `after` 와 `source` 를 적는다. 상황마다 3번씩.

| 상황 | 기대 | after (1·2·3회) | source |
|---|---|---|---|
| 알림 허용, 앱은 뒤에 있음 | 몇 초 안, `notification` | | |
| 알림 허용, 앱을 위로 쓸어 강제 종료 | 몇 초 안, `notification` | | |
| 알림 끔, iOS 26 | 몇 초~수십 초, `widget` (위젯 푸시) | | |
| 알림 끔, iOS 17~18 | 최대 15분 남짓, `widget` (예약) | | |
| 저전력 모드 | 늦어질 수 있음 | | |
| 비행기 모드 10분 → 해제 | 해제 후 알림이 오면 바로 | | |
| 앱을 열었을 때 | 바로 (`widget`, 예산 차감 없음) | | |

- [ ] 알림에 사진이 첨부되어 보인다
- [ ] 위젯 사진이 바뀐 시점과 알림이 뜬 시점이 거의 같다

### 3. 넘겨 보기 · 친구 고르기

- [ ] 사진이 2장 이상이면 오른쪽 위에 점(● ○ ○)이 보이고, 양옆 가장자리에 화살표가 보인다
- [ ] 오른쪽을 누르면 다음 사진, 왼쪽은 이전 사진. 끝에서 누르면 처음으로 돌아간다 (앱은 열리지 않는다)
- [ ] 누르고 바뀌기까지 걸리는 시간이 거슬리지 않는다 (서버에 가지 않고 폰에 받아 둔 사진으로 바꾼다)
- [ ] 가운데를 누르면 **지금 보이는** 사진의 상세 화면이 열린다
- [ ] 넘겨 둔 상태에서 새 사진이 오면 맨 앞(가장 최근)으로 돌아간다
- [ ] 하루가 지나 사진이 1장만 남으면 점과 화살표가 사라진다
- [ ] 위젯을 길게 눌러 [위젯 편집] → 친구를 고르면 그 친구 사진만 나온다 (목록에 친구 이름이 보인다)
- [ ] 그 친구가 보낸 사진이 없으면 「○○님이 사진을 보내면 여기에 떠요」
- [ ] 위젯을 두 개 두고 하나는 「모든 친구」, 하나는 한 친구로 해도 각자 따로 넘어간다
- [ ] 한 친구 위젯도 새 사진이 몇 초 안에 바뀐다 (알림 서비스 확장이 그 위젯의 사진도 같이 받아 둔다)

### 4. 댓글

- [ ] 친구가 댓글을 달면 큰 위젯 아래 2줄, 작은 위젯 1줄이 바뀐다 (보낸 사람 이름 굵게 + 글)
- [ ] 이모지 반응은 위젯에 나오지 않는다 (앱에서만)
- [ ] 긴 댓글은 한 줄에서 잘린다

### 5. 보기

- [ ] 사진이 흐리거나 늘어나지 않는다 (위젯용 600px)
- [ ] 밝은 사진 위에서도 보낸 사람 이름 · 시간 · 댓글이 읽힌다 (위아래 그늘)
- [ ] 다크 · 라이트 모드 둘 다 이상 없다

## 결과가 기대와 다를 때

| 증상 | 먼저 볼 곳 |
|---|---|
| 로그에 `source=notification` 이 안 나온다 | 알림 권한 · APNs 키 · 개발/배포 환경(`APNS_ENV`) 이 맞는지, 서버 로그의 푸시 실패 |
| `after` 는 짧은데 위젯이 안 바뀐다 | 위젯이 캐시를 못 읽는 것: App Group (`group.<번들 ID>`) 이 앱·위젯·알림 확장에 모두 켜져 있는지 |
| 계속 「친구가 사진을 보내면…」 | 서버가 204 를 주는지 (보여줄 친구 사진이 없음), 토큰 만료(30일) |
