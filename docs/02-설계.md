# 마인크래프트판 인생모드 — 설계 (v0.2 방향)

> 전제: `01-인생모드-분석.md`의 이해 (사용자 확인 완료)
>
> **확정된 결정**

| 항목 | 결정 |
|---|---|
| 조작 | 명령어 대신 **스마트폰(G키) + 상호작용 메뉴**, 전부 **클릭**으로 |
| 경찰·의료국 | **사람이 맡음** (AI 경찰 없음) |

| RP 수준 | **중간** (엄격과 라이트 사이) |

## 1. 500명을 위한 서버 구조

### 1.1 사실관계
- **Paper 서버 한 대:** 실제 운영에서 보통 100~200명 수준입니다. 서버는 한 개의 메인 스레드로 돌아가서, 사람이 많아지면 그 스레드가 병목이 됩니다. [추론, 일반적 운영 경험치]
- **Folia (PaperMC 공식 멀티스레드 서버)** [원문: Folia README]
  - 26.2.x 브랜치가 있고, 현재 상태는 BETA입니다.
  - 가까운 청크끼리 묶은 「지역」별로 서로 다른 스레드에서 동시에 처리합니다.
  - 공식 테스트 서버의 최고 동접은 약 330명이었고, **16코어 이상**을 권장합니다.
  - **주의 1:** 플레이어가 흩어져 있어야 효과가 큽니다. 한 도시에 몰려 있으면 지역이 하나로 합쳐져 다시 스레드 하나가 처리합니다.
  - **주의 2:** 플러그인이 Folia 방식(지역·엔티티 스케줄러)으로 만들어져 있어야만 실행됩니다.
- **Paper API에도 Folia 방식 스케줄러가 들어 있습니다.** `RegionScheduler`, `EntityScheduler`, `GlobalRegionScheduler`, `AsyncScheduler`가 있어서, **한 번 만든 플러그인이 Paper와 Folia 양쪽에서 돕니다.** [원문: Paper 26.2 API]
- **Simple Voice Chat**은 Velocity/BungeeCord 프록시를 지원합니다. 음성 포트는 UDP 24454입니다. [원문: SVC README]

### 1.2 결정: 「처음부터 확장 가능하게」
1. **플러그인을 Folia 호환으로 만듭니다.**
   - 메인 스레드를 가정하지 않고, 위치와 엔티티 기준 스케줄러를 씁니다.
   - 공유 데이터는 스레드에 안전한 구조로 둡니다.
   - paper-plugin.yml에 `folia-supported: true`를 넣습니다.
2. **데이터를 외부 DB로 옮깁니다.**
   - 운영: MariaDB/MySQL
   - 개발·소규모: SQLite
   - 저장과 조회는 모두 비동기로 처리하고, 돈은 DB 트랜잭션으로 다룹니다.
   - YAML 파일 저장은 없앱니다.
3. **확장 경로 두 가지를 열어 둡니다.** 실제 부하 테스트로 고릅니다.
   - **A. Folia 단일 월드:** 모두가 하나의 도시에 있어서 FiveM과 가장 비슷합니다.
     - 맵을 여러 지구(도심, 외곽, 북부 등)로 넓게 만들어 사람을 분산시켜야 합니다.
   - **B. 채널 분할:** Velocity 프록시 뒤에 같은 도시 서버를 여러 대(예: 1채널, 2채널) 둡니다.
     - 채널마다 150~250명을 받고, 돈·직업·차량은 DB와 Redis로 공유합니다.
     - 대신 다른 채널 사람과는 만날 수 없습니다.
4. **엔티티 수를 아낍니다.**
   - 리소스팩 차 모델을 쓰면 **차 한 대 = 디스플레이 엔티티 1개**가 됩니다. 지금은 블록 조립식이라 차 한 대에 10개가 넘습니다.
   - 버려진 차는 자동으로 차고로 보냅니다.
5. **하드웨어 기준 (500명):**
   - 16코어 이상 전용 서버, RAM 32~64GB
   - 월드는 미리 생성(pre-generate)해 둡니다.
   - 음성 트래픽 때문에 대역폭이 넉넉해야 합니다. [원문: Folia README 권장치 + 추론]

## 2. 중간 수준 RP 규칙 (초안)

**꼭 지키기 (위반하면 처벌)**
1. 이유 없는 살인·차로 치기 금지 (RDM/VDM)
2. 죽었다 깨어나면 그 사건을 잊기 (뉴라이프)
3. 게임 밖 정보 쓰지 않기 (메타게이밍): 디스코드, 방송, 현실 친분 등
4. 불리할 때 접속 끊기 금지 (콤뱃로그)
5. 총이 겨눠지면 목숨 아끼기 (공포 RP)
6. 뉴비 괴롭히기 금지, 의료국 공격 금지
7. 버그·핵 악용 금지 (영구 밴)

**느슨하게 (편하게 허용)**
- 짧은 OOC 대화는 허용합니다. 폰의 「OOC 채팅」 앱으로 하고, 근접 음성에서는 캐릭터 연기를 유지합니다.
- 경찰 보고서는 의무가 아닙니다. 체포·벌금은 MDT에 **자동 기록**됩니다.
- 서로 합의한 상황극(WWE)은 허용합니다.
- 캐릭터 이름 규칙은 아래 미결정 항목을 참고하세요.

**처벌과 신고**
- 처벌 단계: 경고 → 관리자 감옥 → 기간 정지 → 영구 밴
- 신고: 폰 「관리자 호출」 앱으로 하고, 신고에는 위치와 최근 기록이 자동으로 붙습니다.

## 3. 화면과 조작 설계 (클릭만)

### 3.1 스마트폰 — G키
- 바닐라 「빠른 동작」 키(기본 G)에 서버 메뉴를 연결합니다. [원문 확인]
- 폰 아이템을 우클릭해도 열립니다.
- **폰은 아이템입니다.** 뺏기거나 잃어버리면 쓸 수 없고, 수갑을 찼거나 쓰러진 상태에서도 쓸 수 없습니다.
- 리소스팩으로 폰 프레임과 앱 아이콘을 입힙니다. 그 전에는 버튼 격자 화면을 씁니다.
- **앱 목록 (1차)**

| 앱 | 기능 (모두 클릭) |
|---|---|
| 은행 | 잔액·거래내역, 송금(사람 선택 → 금액 버튼), 청구서 납부 |
| 연락처·전화 | 근처에서 교환한 연락처, 통화 (음성: SVC 1:1 채널) |
| 문자 | 정해진 문장 버튼(「어디야?」, 「지금 갈게」, 「도와줘!」, 「고마워」 등) + 내 위치 보내기 |
| 112 / 119 | 버튼 한 번으로 위치가 담긴 신고. 신고 사유는 버튼(강도, 폭행, 교통사고, 쓰러진 사람) |
| 서비스 | 근무 중인 택시·정비·의료국·경찰 목록과 바로 호출 |
| 직업 | 내 직업·계급·출퇴근 버튼. 보스는 직원 관리(고용·승진·해고·급여) |
| 차고 | 내 차 목록·위치, 차 부르기(차고 근처일 때) |
| 지도·GPS | 주요 장소 목록 → 클릭하면 경로 안내(보스바 화살표) |
| SNS | 정해진 글 형식 + 좋아요 → 평판 (2차) |
| 관리자 호출 | 신고, 도움 요청 |
| 경찰 전용: MDT | 수배자, 최근 신고, 시민 기록 조회, 벌금·체포 기록 |
| 의료국 전용 | 쓰러진 사람 목록과 위치 |

### 3.2 상호작용 메뉴 — 대상을 보고 우클릭
FiveM의 Alt(3rd-eye)에 해당합니다. 대상과 내 상태에 맞는 버튼만 보입니다.

| 대상 | 누구에게나 | 경찰(출근 중) | 의료국(출근 중) |
|---|---|---|---|
| 사람 | 신분증 보여주기, 연락처 교환, 돈 주기(금액 버튼), 청구서 보내기(직업이 있을 때) | 수갑 / 풀기, 연행, 차에 태우기, 수색, 압수, 벌금(벌금표 버튼), 감옥(형량 버튼), 신원조회 | 상태 확인, 치료, 소생(쓰러진 사람) |
| 쓰러진 사람 | 응급키트로 소생 시도 | 위와 같음 | 소생 |
| 차 | 타기, 트렁크, 잠금/열기(열쇠 있을 때) | 압류, 차량 조회 | — |
| 건물·금고 | 상점, ATM, 금고 털기(조건 충족 시) | — | — |

### 3.3 입력 없는 금액·형량 선택
- **금액:** `[-1만] [+1천] [+1만] [+10만]` → 미리보기 `현재: 35,000원` → `[보내기] [취소]`
- **벌금:** 범죄 버튼(벌금표) 여러 개 선택 → 합계 자동 계산 → `[부과]`
- **감옥:** 죄목 선택 → 형량 자동 계산(죄목별 분 단위) → `[수감]`

## 4. 시스템 명세 (핵심만)

### 4.1 캐릭터
- **필드:** 고유 시민번호, 캐릭터 이름, 직업·계급, 근무 여부, 면허(운전·무기), 현금·은행·검은돈 아이템, 배고픔·목마름·스트레스, 쓰러짐·감옥 상태
- **처음 접속:** 규칙 동의(대화창) → 캐릭터 생성 → 지원품(폰, 신분증, 정착금 1억) → 그다음은 자유 (퀘스트·렌트카 없음, `04-기획서.md` 2장)

### 4.2 직업·회사
- **공무직:** 경찰, 의료국
  - 계급표, 출퇴근, 무기고와 차고 권한이 계급별로 다릅니다.
  - 월급은 시청 국고에서 나갑니다.
- **민간 회사:** 정비소, 택시, 식당 등
  - 회사 계좌, 보스 메뉴(고용·승진·해고·급여), 청구서 수입
- **시민 알바:** 택배, 채광, 벌목, 낚시, 농사 — 즉시 시작할 수 있습니다.
- **월급:** 근무 중일 때만, 일정 주기마다 지급하고 소득세를 뗍니다.

### 4.3 경찰
- **디스패치:**
  - 112 신고와 자동 신고(총소리, 차량 절도, 강도, 쓰러진 사람)가 출근한 경찰 폰에 알림으로 옵니다.
  - `[응답]`을 누르면 위치 안내가 시작됩니다.
- **체포 흐름:** 수갑 → 연행(경찰을 따라오게) → 차 뒷좌석 → 수색과 압수 → 벌금(청구서) 또는 감옥(분 단위) → MDT 자동 기록
- **최소 경찰 수:** 출근 경찰 수를 실시간으로 집계하고, 강도 같은 범죄 콘텐츠는 이 숫자가 기준 이상일 때만 열립니다.
- **남용 방지:** 모든 체포·벌금·압수는 기록되고, 사유(죄목 버튼)가 필수입니다. 형량과 벌금에는 상한이 있습니다.

### 4.4 의료국과 쓰러짐
- **쓰러짐:** 체력이 0이 되면 쓰러져서 기어가는 자세가 됩니다. 공격과 아이템 사용은 불가능하고, 화면에 출혈 타이머가 표시됩니다.
- **구조 요청:** 쓰러진 상태에서 G를 누르면 119 구조 요청 버튼이 나옵니다. 자동 신고도 함께 갑니다.
- **치료:** 의료국이 소생 진행바를 채우면 살아나고, 비용은 의료국 회사 수입이 됩니다. 응급키트가 있으면 일반인도 소생을 시도할 수 있습니다.
- **타이머:** 일정 시간 뒤 「포기」를 고를 수 있고, 시간이 다 되면 병원 리스폰 + 병원비 + 뉴라이프입니다.
- **의료국이 적을 때:** 근무 중인 의료국이 적으면 병원 셀프 체크인이 열립니다.

### 4.5 경제
- **돈의 형태:** 현금 / 은행 / **검은돈(아이템)**. 검은돈은 범죄 보상이고, 압수 대상이며, 세탁 수수료를 내야 씁니다.
- **돈을 회수하는 장치:** 소득세, 벌금, 병원비, 수리비, 압류 해제비. 인플레이션을 막는 용도입니다.
- **원칙:** 모든 돈 계산은 서버와 DB 트랜잭션에서만 하고, 이상 거래는 로그로 남깁니다.

### 4.6 범죄 콘텐츠
- **편의점·은행 강도:**
  - 출근 경찰 최소 인원, 도구, 미니게임, 경보, 쿨타임이 있습니다.
  - 보상은 검은돈입니다.
- **차량 절도:** 락픽 미니게임, 실패하면 경보, 자동 신고가 갑니다.
- **2차 콘텐츠:** 마약(재배 → 가공 → 판매), 갱 조직

### 4.7 차량
- **기본:** 열쇠(아이템), 연료, 손상과 수리
- **보관:** 차고에서 넣고 빼고, 서버를 재시작하면 차고로 돌아갑니다. 경찰이 압류할 수 있습니다.
- **모델:** 리소스팩 단일 모델로 만들어 엔티티 수를 줄입니다.

### 4.8 음성 (Simple Voice Chat)
- **근접:** 거리는 SVC 설정을 따릅니다.
- **전화:** 폰 통화를 하면 두 사람을 하나의 음성 채널로 묶습니다.
- **무전:** 출근 중인 경찰과 의료국에게 전용 무전 채널이 있습니다.
- **배포:** 플레이어에게는 Fabric + SVC 모드팩 파일(.mrpack) 하나를 나눠 줍니다.

### 4.9 운영 도구
- 관리자 호출 앱, 관리자 감옥, 경고 누적, 거래·체포 로그 조회

## 5. 개발 단계

| 단계 | 내용 | 끝나면 할 수 있는 것 |
|---|---|---|
| **1. 기반** ✅ v0.2.0 | Folia 호환 구조, DB 저장소, 캐릭터 생성(이름 1회·주민번호), 폰(G키), 상호작용 메뉴, 112/119 신고, 길 안내, 명령어 → 폰 이전, AI 경찰 삭제 | G로 폰 열기, 은행·송금 클릭, 사람 우클릭 메뉴 |
| **2. 공무직** | 직업·계급·출퇴근·보스 메뉴·회사 계좌, 경찰(디스패치·수갑·연행·수색·벌금·감옥·MDT), 쓰러짐·의료국 | 사람 경찰·의료국으로 RP 시작 가능 |
| **3. 경제·범죄** | 검은돈·세탁, 청구서, 세금, 강도(최소 경찰 연동), 차량 절도 | 범죄 ↔ 경찰 순환 |
| **4. 리소스팩·음성** | 폰 화면 디자인, 차·총 모델, HUD 아이콘, SVC 연동(전화·무전), 모드팩 배포 | 「인생모드다운」 경험 |
| **5. 생활** | 차고·연료·압류, 집, 목마름·스트레스, 면허, 회사(정비·택시·식당), 뉴비 지원, SNS·평판 | 장기 운영 |
| **6. 규모** | 부하 테스트 → Folia 또는 채널 분할 결정, Redis 동기화 | 500명 운영 |

## 6. 결정된 것 (사용자 확인)
1. **하나의 큰 도시** → Folia 단일 월드. 거점은 서로 1km 이상 떨어뜨려 부하를 분산합니다 (`03-도시맵-제작.md` 참고).
2. **캐릭터 이름:** 캐릭터를 만들 때 딱 한 번 입력하고, **주민번호를 자동으로 부여**합니다.
   - 예: `261004-1000001` = 도시에 처음 온 날 + 순번
3. **도시 맵:** 랜드마크는 직접 짓고, 나머지는 실제 지도로 생성(Arnis)한 뒤 라이선스가 확인된 건물로 채웁니다.
