## 1. 컨셉 [확정]

| 항목 | 결정 |
|---|---|
| 도시 배경 | 서울과 인천을 한 장에 압축한 가상 수도권입니다. GTA의 로스산토스가 LA를 압축한 것과 같은 방식입니다 |
| 이용 연령 | **연령 제한 없음.** 인증 절차가 까다로워서 두지 않습니다 |
| 콘텐츠 수위 | 총·강도·갱은 있습니다. 마약은 가상 물질로 순화하고, 선정적인 내용은 없습니다 |
| 입장 방식 | **누구나 바로 입장** (화이트리스트 없음) |
| 규칙 교육 | 입국 심사의 동의 버튼 (지금 방식 그대로) |
| 지명·상호 | 지명은 실제 그대로 씁니다. 가게·브랜드 이름과 로고는 패러디로 바꿉니다 |
| RP 수준 | 엄격과 라이트 사이 |
| 운영 목표 | **공개 서버로 키우기.** 후원으로는 꾸미기 아이템만 팝니다. 돈·차·무기처럼 게임에 유리한 것은 마인크래프트 규정상 팔 수 없습니다 |
| 규모 | 동접 500명, 하나의 큰 도시 (Folia 단일 월드) |
| 음성·리소스팩 | 근접 음성(Simple Voice Chat)과 리소스팩을 씁니다 |

### 이 결정 때문에 해야 할 일 [제안]
- **누구나 들어오므로 운영 도구를 일찍 준비합니다.**
  - 폰 신고 앱, 경고 누적, 관리자 감옥
  - 행동 기록: 누가 누구를 죽였는지, 차로 쳤는지
- **규칙 교육이 동의 버튼뿐이므로**, 처음 규칙을 어기면 바로 처벌하지 않고 어떤 규칙인지 알려 주는 안내부터 띄웁니다.
- **뉴비 표시:** 캐릭터를 만든 뒤 3일 동안 머리 위에 새싹 표시를 붙입니다(2장).

### 일반인 서버 재조사에서 나온 원칙 [제안] (`05-일반인-서버-조사.md`)
- **적은 인원에서도 돌아가게 합니다.**
  - 국내 일반 서버는 대부분 동접 20~60명입니다. 500명은 목표이고 출발점이 아닙니다.
  - 혼자 하는 직업과 NPC 손님(3.5·3.6)이 이 역할을 합니다.
  - 강도 최소 경찰 수 같은 숫자는 접속 인원에 맞춰 바뀌게 합니다.
- **일반인은 성장·수집 때문에 접속합니다.** 직업 등급, 차, 집, 칭호를 일찍 넣습니다.
- **후원**
  - 꾸미기만 팝니다.
  - **랜덤박스는 현금으로 팔지 않습니다.** 플레이 보상이나 게임 돈으로만 얻습니다(2.3).
  - 후원과 직책(공무직 계급, 조직 간부)은 완전히 분리합니다.
  - 꾸미기는 플레이로 쌓는 마일리지로도 얻을 수 있게 합니다.

## 2. 오픈월드 원칙과 처음 접속

### 2.1 원칙 [확정]
- **완전 오픈월드입니다.** 정해진 순서나 경로가 없고, 무엇을 할지는 유저가 스스로 정합니다.
- **넣지 않는 것:** 퀘스트, 첫걸음 안내, 튜토리얼, 일일 의뢰
- **넣는 것:** 출석 보상, 마인리스트 추천 보상, 광고 시청 보상, 시즌 랭킹, 랜덤박스 (2.3)
- **정보는 주되 시키지 않습니다** [제안]
  - 폰 지도 앱에 알바 장소와 가게 위치가 나옵니다.
  - 폰 알바 앱에서 지금 할 수 있는 알바 목록을 봅니다.
  - 공항과 시청에 안내 NPC를 둡니다. 물어보면 알려 주기만 합니다.
  - 사람이 맡는 뉴비 도우미(3.1)도 있습니다.
- 면허 같은 제도는 퀘스트가 아니라 **도시의 규칙**으로만 둡니다.
  - 예: 무면허로 운전하면 경찰이 단속할 수 있습니다.
  - 자세한 내용은 5장(범죄·처벌표)에서 정합니다.

### 2.2 처음 접속 [확정]

| 항목 | 내용 |
|---|---|
| 시작 | 공항에서 입국 심사(규칙 동의, 이름, 주민번호)를 마치면 끝. 그다음은 자유입니다 |
| 받는 것 | 스마트폰, 신분증, **정착금 300만 원** |
| 새싹 표시 | 캐릭터를 만든 뒤 **3일 동안 머리 위에 새싹(🌱)**이 붙습니다. 누가 새로 온 사람인지 보여 주는 표시입니다 |
| 자는 곳 | **없습니다.** 접속하면 나갔던 자리에서 그대로 시작합니다 |

- **새싹 관련** [제안]
  - 새싹을 단 사람을 괴롭히거나 강도·사기를 치면 처벌을 무겁게 합니다(7장).
  - 시스템으로 공격 자체를 막지는 않습니다.

### 2.3 보상 장치 [확정: 넣는다 / 제안: 방식]
정해진 길을 시키는 퀘스트가 아니라, **접속하고 서버를 키우는 데 대한 보상**입니다.

| 장치 | 방식 [제안] |
|---|---|
| 출석 보상 | 하루 한 번, 접속해서 일정 시간 놀면 받습니다. 연속 출석일수에 따라 보상이 조금씩 커집니다 |
| 마인리스트 추천 보상 | 마인리스트(minelist.kr)에서 서버를 추천하면 게임 안에서 바로 받습니다 |
| 광고 시청 보상 | 하루 3회까지 |
| 시즌 랭킹 | 시즌(예: 3개월)마다 부문별 순위를 매기고, 끝나면 그 시즌 한정 꾸미기·칭호를 줍니다 |
| 랜덤박스 | 위 보상으로 받거나 게임 돈으로 삽니다 |

- **마인리스트 추천 보상**
  - 마인리스트는 Votifier 방식으로 「누가 추천했는지」를 서버에 알려 줍니다 [요약].
  - Votifier 수신 기능을 우리 플러그인에 직접 넣습니다. 기존 Votifier 플러그인이 Folia에서 도는지 확인되지 않았기 때문입니다.
  - 출처: https://docs.minelist.kr/votifier/introduction
- **광고 시청 보상** [제안, 확인 필요]
  - 마인크래프트 안에서는 영상 광고를 띄울 수 없습니다.
  - 그래서 **웹페이지에서 보상형 광고**를 보고, 서버가 시청을 확인한 뒤 보상하는 방식입니다.
  - 구현하기 전에 광고 회사 정책(게임 보상 허용 여부)과 마인크래프트 사용 가이드라인을 확인합니다.
- **시즌 랭킹 부문 예시** [제안]: 직업별 등급, 번 돈, 차 도감, 경찰 출동 수, 의료국 소생 수
- **랜덤박스 원칙** [제안]
  - **현금으로는 팔지 않습니다.** 마인크래프트 사용 가이드라인은 게임에 영향을 주는 보상이 든 랜덤박스를 현금으로 파는 것을 금지합니다 [요약].
  - 꾸미기만 든 상자를 현금으로 팔더라도 같은 상자를 플레이로도 얻을 수 있어야 하고, 확률을 공개해야 합니다.
  - 출처: https://www.minecraft.net/en-us/usage-guidelines , https://minehut.wiki.gg/wiki/MUG_FAQ
  - 게임 돈으로 사는 랜덤박스는 돈이 빠져나가는 곳(4장) 역할도 합니다.

### 2.4 경제의 출발점 [확정] → 4장
- 정착금은 300만 원입니다.
- **물건값은 현실 가격 그대로** 쓰고, 시급만 게임 속도로 올립니다(4장).
- **혼자 알바를 1시간 정도 하면 저렴한 경차를 살 수 있게** 합니다.
- 그 위의 차, 집, 가게 같은 목표는 유저가 알아서 정합니다. 가격만 4장에서 정합니다.

## 3. 직업·조직표

### 3.1 큰 그림

| 분류 | 직업 | 거점 | 뽑는 방식 |
|---|---|---|---|
| 공무직 | **경찰** | 강남(강남경찰서) 한 곳 [확정] | 조건 + 게임 안 면접 [확정] |
| 공무직 | **의료국** | 대학병원 | 조건 + 게임 안 면접 [확정] |
| 공무직 | 시청 | 중구 | 오픈 때는 사람이 맡지 않습니다. 면허·세금·사업자 등록은 NPC 창구가 처리합니다 [제안] |
| 민간 회사 | 정해진 회사 12곳 (3.4) | 구역마다 | 사장 공모 → 운영진 임명 [확정] |
| **혼자 하는 직업** | 14종 (3.5) | 구역마다 흩어 놓음 | 폰에서 바로 시작. 다른 플레이어가 필요 없음 |
| 범죄 조직 | 갱 4~6개 | 아지트 | 승인제 [확정] |

**공통 규칙** [제안]
- 한 사람이 **직업 1개와 조직 1개를 따로** 가집니다(FiveM 방식). 예: 낮에는 정비사, 밤에는 갱.
- 공무직(경찰·의료국)은 갱에 들어갈 수 없습니다.
- **출근 중에만** 월급을 받고 신고를 받습니다. 10분 동안 움직이지 않으면 자동으로 퇴근합니다.
- 강도에 필요한 「최소 경찰 수」는 **출근 중인 경찰**만 셉니다.
- **공무직 쏠림 방지:** 일반 서버에서는 경찰이 부족하고 공무직이 의료국으로 쏠리는 문제가 흔했습니다(05 문서).
  - 경찰 출근 보상을 줍니다.
  - 신입용 매뉴얼을 둡니다.
  - 경찰과 의료국의 정원과 보상을 함께 조정합니다.
- **뉴비 도우미** (시청 소속 상호작용 직업)
  - 공항과 시청에서 뉴비를 안내하고, 안내한 만큼 보상을 받습니다.
  - 고인물 벽을 낮추려고 둡니다(05 문서).

**동접 500명일 때 목표 인원** [제안]

| 직업 | 정원 (등록) | 가장 붐빌 때 출근 |
|---|---|---|
| 경찰 | 150명 | 50~60명 (접속자의 10~12%) |
| 의료국 | 80명 | 25~30명 |
| 민간 회사 직원 | 회사당 5~15명 | 60~80명 |
| 갱 | 조직당 8~15명 | 최대 90명 |

나머지 절반 정도는 일반 시민입니다. 알바를 하거나 자유롭게 RP를 합니다.

### 3.2 공무직 뽑기 [확정: 방식 / 제안: 수치]
1. **임명:** 운영진은 맨 위만 임명합니다. 경찰청장 1명, 의료국장(병원장) 1명입니다.
2. **지원 조건:** 누적 플레이 10시간 이상, 최근 7일 동안 운영진 경고 없음
3. **지원:** 경찰서나 병원 안내 NPC를 우클릭해 [지원하기]를 누릅니다.
4. **면접:** 면접 담당자(아래 표)의 폰에 알림이 갑니다. 만나서 게임 안에서 면접을 봅니다.
5. **채용:** 서장급이 폰에서 [채용]을 누릅니다. 3일 동안은 수습이고 권한이 제한됩니다.
6. **관리:** 서장급이 폰의 보스 메뉴에서 승진·강등·해고합니다. 모든 처리는 기록으로 남습니다.

### 3.3 계급과 권한 [제안]

**경찰** (실제 계급을 줄여서 씁니다)

| 계급 | 정원 | 할 수 있는 것 |
|---|---|---|
| 순경 (수습 포함) | 제한 없음 | 순찰, 수갑, 연행, 테이저, 작은 벌금 |
| 경장 · 경사 | 제한 없음 | 수색·압수, 감옥 보내기, 권총 |
| 경위 | 서마다 6명 | 팀장, 소총·특수장비, 면허 취소 |
| 경감 · 경정 | 서마다 3명 | 면접, 은행 강도 같은 큰 사건 지휘 |
| 총경 (서장) | 서마다 1명 | 채용·승진·해고, 서 예산 |
| 치안총감 (경찰청장) | 1명 | 전체 관리, 서장 임명 (운영진이 임명) |

- **교도소 호송:** 경찰이 구인천 부두의 호송선 선착장까지 데려가면 섬 교도소로 옮겨집니다.

**의료국** (대학병원 직함)

| 계급 | 정원 | 할 수 있는 것 |
|---|---|---|
| 인턴 (수습 포함) | 제한 없음 | 붕대 치료, 구급차 운전, 환자 옮기기 |
| 레지던트 | 제한 없음 | 쓰러진 사람 소생 |
| 전문의 | 15명 | 약 처방, 소생 시간 단축 |
| 교수 (과장) | 5명 | 면접, 큰 사고 현장 지휘 |
| 부원장 | 2명 | 채용·승진·해고 |
| 병원장 (의료국장) | 1명 | 전체 관리, 치료비 조정 (운영진이 임명) |

- 의료국은 **중립**입니다. 무기가 없고, 의료국을 공격하면 무겁게 처벌합니다(7장 규칙).
- 거점이 대학병원 한 곳이라 송파·광진처럼 먼 곳은 구급차로 2분쯤 걸립니다. 그래서 쓰러진 뒤 출혈 시간을 넉넉하게 잡습니다(5장).
- 근무 중인 의료국이 2명 미만이면 병원 셀프 체크인이 열립니다(설계 문서 4.4).

### 3.4 민간 회사 — 오픈 때 정해 둘 회사 [확정: 방식 / 제안: 목록]

| 회사 | 수 | 위치 | 하는 일 |
|---|---|---|---|

| 택시 | 1 | 중구 기차역 | **플레이어가 부르면 출동** [확정]. 목적지까지 태우고 요금 청구 |
| 식당·카페 | 4 | 명동, 이태원, 홍대, 여의도 | 음식 판매 (배고픔 시스템이 생기면 수요가 생깁니다) |
| 클럽 | 1 | 홍대 | 공연, 입장료, 음료 |
| PC방 | 1 | 홍대 | 미니게임 대회, 이용료 |
| 차 대리점 | 1 | 강남 | 새 차·중고차 판매 수수료 |
| 방송국 | 1 | 여의도 | 기자, 뉴스 앱에 기사, 서버 행사 중계 |
| 부동산 | 1 | 청라 | 분양 필지·집 중개 수수료 |

- **택시와 출장 정비는 사람을 상대하는 직업**입니다 [확정]. 정비소 건물은 따로 두지 않고 정비공이 출장을 갑니다.
  - 플레이어가 폰 「호출」 앱에서 [택시 부르기]나 [정비 부르기]를 누릅니다.
  - 출근 중인 기사·정비공에게 위치와 함께 알림이 갑니다.
  - [응답]을 누르면 길 안내가 시작됩니다. 112·119와 같은 방식입니다.
- **아무도 출근하지 않았을 때** [제안]
  - 택시 대신 버스나 렌트카를 탑니다.
  - 정비 대신 비싼 수리 키트(일부만 고쳐짐)를 씁니다.
  - 의료국이 없을 때 병원 셀프 체크인을 여는 것과 같은 원리입니다.
- **사장 공모:** 지원서를 받아 운영진이 임명합니다.
- **사장이 하는 일:** 보스 메뉴에서 고용·해고·급여를 정합니다. 회사 계좌로 들어온 돈으로 직원 급여와 재료비를 냅니다.
- **사장 교체:** 14일 동안 활동이 없거나 회사 계좌가 바닥나면 다시 공모합니다.
- **개인 창업:** 회사 자리가 잡힌 뒤에 엽니다(5단계).

### 3.5 혼자 하는 직업 — 다른 플레이어 없이 돈 벌기 [확정: 목록 14종, 미니게임 없음 / 제안: 세부]

**원칙**
- 다른 사람이 없어도 **언제든 혼자** 할 수 있습니다. 새벽이나 사람이 적은 날에도 할 일이 있어야 합니다.
- 폰 「알바」 앱에서 바로 시작합니다. 시작 위치를 구역마다 다르게 둬서 사람이 도시 전체로 퍼지게 합니다(서버 렉 분산).
- **미니게임은 넣지 않습니다** [확정]. 운전하는 일은 지도에 찍힌 지점을 차례로 도는 것(찍고, 찍고, 찍고)이 전부입니다.
- 할수록 레벨(숙련도)이 오르고 수입이 늘어납니다. 등급이 오르면 더 큰 차, 새 장비, 새 일거리가 열립니다.
- 혼자 해도 되지만, 사람과 엮이면 더 재미있게 만듭니다.
  - 현금수송차는 강도의 표적이 됩니다.
  - 잡는 직업과 가공하는 직업이 나뉘어 있어서 플레이어끼리 사고팔 이유가 생깁니다.
- **매크로 방지:** 목적지와 순서를 매번 바꿉니다.
- **일하는 지점** [제안]: 배달지(빌라 문패 번지, 상가), 쓰레기 봉투, ATM 같은 지점은 맵 생성기가 건물을 지을 때 같이 뽑아 파일로 내보내고, 플러그인이 읽습니다. 운영진은 명령어로 몇 개만 더하거나 뺍니다.

**운전하는 일** (회사 차 지급)

| 직업 | 시작 위치 | 하는 일 |
|---|---|---|
| 택배 | 대형시장 물류센터 | 탑차에 상자를 싣고, 지도에 찍힌 배달지(빌라·상가 주소)를 차례로 돌며 내려놓기. 다 돌면 물류센터로 (이미 있음) |
| 화물 트럭 | 구인천 항만 | 컨테이너 트레일러를 받아 물류센터, 공장, 시장으로 운반 |
| 현금수송 | 여의도 은행 본점 | 금고에서 현금 가방을 받아 장갑차에 싣고 ATM을 돌며 채우기. 현금이 떨어지면 금고로 돌아가 다시 챙겨서 반복. 수입이 높지만 강도의 표적 |
| 환경미화 | 중구 시청 차고지 | 쓰레기차로 노선을 돌며 건물 앞 종량제 봉투 수거. 차가 차면 차고지 옆 적환장에 비움 |
| 항만 하역 | 구인천 부두·컨테이너 야적장 | 지게차로 배에서 내린 컨테이너를 정해진 야적장 칸이나 화물 트럭 트레일러로 옮기기. 등급이 오르면 크레인 |
| 음식 배달 | 대형시장 먹자골목, 명동, 홍대 | 스쿠터로 가게에서 음식을 받아 빌라·원룸 문 앞까지. 플레이어가 폰 배달앱으로 시키면 배달 기사 플레이어에게 먼저 감 |
| 대리운전 | 밤에 이태원, 여의도, 홍대, 강남 | 전동킥보드로 콜 장소에 가서 손님(NPC)의 차를 손님 집까지 운전. 끝나면 킥보드로 다음 콜. 차 없는 뉴비도 운전할 수 있음. 플레이어도 폰에서 대리를 부를 수 있음 |

**채집·가공** (걸어서 할 수 있음)

| 직업 | 장소 | 하는 일 |
|---|---|---|
| 갯벌 조개잡이 | 구인천 남쪽 해안 갯벌 | 썰물 때 호미로 진흙을 긁어 바지락·동죽·맛조개·낙지 캐기. 밀물 시간이 되면 나와야 함. 수산시장에 팔거나 손질로 |
| 수산물 손질 | 대형시장 수산시장 | 잡아 온 생선을 손질대에서 손질해 회·손질 생선으로 비싸게 판매 (시장 상인, 플레이어 식당) |
| 낚시 | 여의도 한강공원(민물), 구인천 부두·방파제(바다) | 마인크래프트 낚시 그대로. 장소·시간·날씨마다 어종이 다름. 희귀 어종 있음 |
| 나무꾼 | 북한산 기슭 벌채 구역 | 표시된 구역의 나무만 베기(밑동을 베면 통째로 쓰러짐). 원목은 목재 집하장에 판매. 묘목을 심으면 보너스 |
| 농부 | 청라 외곽 농지 (간척지 논밭) | 밭을 빌려 심고 키워 수확 (쌀·배추·무·감자·고구마·고추). 접속하지 않아도 시간 기준으로 자람. 농협 공판장·시장에 판매 |
| 광부 | 북한산 채석장 | 화강암과 드물게 나오는 광물을 캐서 광물 거래소에 판매 (이미 있음). 채석장은 일정 시간마다 다시 채워짐 |
| 축산 | 청라 외곽 농장 | 축사 칸을 빌려 소·돼지·닭을 키우고 번식, 달걀·우유 수거, 다 크면 출하해 시장 정육점으로. 사료는 농부에게 사면 쌈. 서버 부하 때문에 한 사람당 마릿수 상한 |

**직업끼리 이어지는 흐름**
- 바다: 낚시·갯벌 → 수산물 손질 → 수산시장, 식당
- 항구: 항만 하역 → 화물 트럭 → 물류센터 → 택배
- 밭: 농부 → 축산(사료) → 시장 정육점, 식당
- 산: 나무꾼 → 목재 집하장, 광부 → 광물 거래소

넣지 않기로 한 것 [확정]: 편의점·카페 알바, 경비원, 공항 지상조업, 전단지, 버스 기사, 견인차, 한강 유람선, 전기·신호등 수리, 건설 노동, 연구소 조수, 고물 줍기.
택시와 정비공은 이 목록에 넣지 않습니다. 플레이어가 불러야 일하는 직업이라 3.4(민간 회사)에 있습니다.

### 3.6 사람이 적을 때는 NPC가 손님 역할 [제안]
회사와 공무직도 다른 플레이어가 없을 때 할 일이 있어야 합니다.
- **NPC는 손님·환자·작은 사건 역할만** 합니다. 경찰과 범죄자는 언제나 사람이 맡습니다.

| 직업 | 사람이 없을 때 하는 일 |
|---|---|
| 경찰 | 순찰 지점 돌기, NPC 교통 단속(과속·불법주차), 분실물·소음 같은 가벼운 NPC 신고 처리 |
| 의료국 | NPC 응급환자 이송 (교통사고, 등산 사고 등) |
| 식당·카페 | NPC 손님 주문 |
| 방송국 | 도시에서 일어난 사건(강도, 사고 기록)으로 기사 쓰기 |

- 플레이어의 신고나 손님이 생기면 NPC 일보다 **먼저** 알리고, 보상도 더 큽니다.
- **택시와 출장 정비는 NPC 손님이 없습니다** [확정]. 플레이어가 불러야 일합니다(3.4).

**수입 원칙** [제안, 4장에서 확정]
- 혼자 하는 일만 해도 생활이 되게 합니다.
- 사람과 엮이는 일은 시간당 수입을 조금 더 높게 해서 사람을 만날 이유를 만듭니다.
  - 사람과 엮이는 일: 회사 손님, 신고 출동, 범죄
  - 예: 혼자 하는 일이 100이면, 사람과 엮이는 일은 120~150

### 3.7 범죄 조직 (갱) [확정: 승인제 / 제안: 세부]
- **수:** 4~6개만 승인합니다.
- **인원:** 조직마다 8~15명입니다.
- **지원 조건:** 4명 이상 모여서 조직 이름, 콘셉트, 활동 계획을 냅니다.
- **아지트 후보:** 구인천 폐공장(지어져 있음), 홍대 뒷골목, 북한산 은신처, 광진구 빌라촌, 청라 공사장

- **조직 안 계급:** 보스 → 간부 → 조직원. 보스가 영입하고 내보냅니다.
- **해체:** 30일 동안 활동이 없거나 운영진 경고가 쌓이면 해체합니다.
- **충돌 상한:** 같은 두 조직이 하루에 정해진 횟수 이상 싸우면 일정 시간 동안 서로 공격할 수 없게 합니다.
  - 국내 일반 서버(세움)의 규칙을 시스템으로 옮긴 것입니다.
- 범죄 종류, 보상, 영역 다툼은 5장(범죄·처벌표)에서 정합니다.

### 3.8 나중에 넣을 것
- **시장 선거:** 세율과 도시 행사를 정합니다.
- **변호사·판사:** 재판 RP
- **경찰 세부 부서:** 형사, 특공대, 교통, 해양경찰(교도소 섬·밀수)
- **스포츠 구단:** 마포 축구장, 잠실 야구장, 청라 돔구장

## 4. 경제 밸런스

### 4.1 기준 [확정]

| 항목 | 결정 |
|---|---|
| 물건값 | **현실 가격 그대로** (2026년 한국 기준) |
| 시급 | **게임 속도.** 현실보다 훨씬 높게 해서 아래 목표 시간을 맞춥니다 |
| 정착금 | **300만 원** |
| 첫 차 | 혼자 알바 **약 1시간**이면 중고 경차 (정착금 포함) |
| 최고급 차 | 혼자 알바 **약 30시간**이면 슈퍼카 |
| 배고픔·목마름 | **넣습니다** |
| 차 유지비 | **연료 + 수리.** 고장 나면 정비공을 불러 출장 수리를 받습니다. 정비소 건물은 없습니다 |
| 병원비 | 죽으면 **현금의 일정 비율** |

- 현실에서 경차와 슈퍼카의 가격 차이는 약 30배입니다. 그래서 「1시간 경차, 30시간 슈퍼카」 목표와 현실 가격이 그대로 맞아떨어집니다.

### 4.2 버는 돈 [제안]

| 일 | 시간당 |
|---|---|
| 혼자 하는 알바 | 등급 1에서 **700만 원**, 최고 등급에서 **1,400만 원** (평균 약 1,000만 원) |
| 사람과 엮이는 일 (택시, 출장 정비, 회사 손님) | 혼자 하는 일의 1.2~1.5배 (4.5의 시청 수당 포함) |
| 경찰·의료국 | 근무 중 10분마다 월급: 가장 낮은 계급 120만 원, 가장 높은 계급 240만 원<br>여기에 출동·치료 보상을 더합니다 |
| 범죄 | 더 높지만 검은돈입니다. 세탁 수수료와 압수 위험이 있습니다 (5장) |
| 보상 장치 (2.3) | 출석·추천·광고는 작은 금액과 랜덤박스 |

- 예: 택배 한 건(약 3분)은 50만 원 안팎입니다.

### 4.3 가격 [제안, 현실 가격 기준]

**차** (처음부터 그 차 하나만 모을 때 걸리는 시간)

| 차 | 가격 | 혼자 알바로 |
|---|---|---|
| 중고 경차 | 800만 원 | 정착금 + 약 1시간 |
| 새 경차 | 1,500만 원 | 약 1.5시간 |
| 세단 | 3,500만 원 | 약 3.5시간 |
| SUV | 5,000만 원 | 약 5시간 |
| 스포츠카 | 1.5억 | 약 15시간 |
| 슈퍼카 | 3억 | 약 30시간 |
| 한정 차 | 팔지 않음 | 랜덤박스, 시즌 보상으로만 |

**생활**

| 항목 | 가격 |
|---|---|
| 편의점 도시락 | 5,000원 |
| 식당 한 끼 | 1만~3만 원 |
| 커피 | 5,000원 |
| 기름 가득 | 경차 6만 원 ~ 대형차 12만 원 |
| 운전면허 시험 | 10만 원 |
| 신분증 재발급 | 5,000원 |
| 출장 수리 | 고장 정도에 따라 10만~수백만 원 |
| 수리 키트 | 300만 원 (게임 아이템. 정비공이 아무도 없을 때 쓰고 일부만 고쳐짐) |
| 랜덤박스 | 500만 원 (혼자 알바 약 30분치) |
| 병원비 | 현금의 20% |

**배고픔·목마름** [제안]
- 약 3시간이면 바닥납니다. 바닥나면 체력이 조금씩 줄어듭니다.
- NPC 편의점은 어디에나 있어서 혼자 노는 사람도 불편하지 않습니다.
- 식당·카페 음식은 더 좋은 효과가 있어서 플레이어 가게에 손님이 생깁니다.

**주의할 점** [추론]
- 시급이 게임 속도라서 음식, 기름, 면허 같은 생활비는 거의 부담이 되지 않습니다. 생활비로는 돈이 회수되지 않습니다(4.4).
- 벌금을 현실 금액(범칙금 몇만 원)으로 하면 처벌 효과가 없습니다. 벌금은 5장에서 **게임 시급 기준**으로 따로 정합니다.

### 4.4 돈이 빠져나가는 곳 [제안]
- **가장 큰 회수처는 NPC에게 사는 것 자체입니다.**
  - 차, 꾸미기, 랜덤박스를 사면 그 돈은 경제에서 사라집니다.
- **세금:**
  - 월급·알바 소득세 8%
  - 차를 살 때 취득세 5%
- **병원비:** 현금의 20%. 현금 기준이라서 큰돈은 은행에 넣고 다니게 됩니다.
- **벌금:** 게임 시급 기준 (5장)
- **크게 고장 난 차의 수리비**
- **다 산 사람도 계속 쓰는 곳:** 랜덤박스, 시즌 한정 꾸미기, 새로 나오는 차
- **은행 이자는 없습니다.**

### 4.5 회사 돈과 시청 수당 [제안]
- **문제:** 손님이 내는 돈은 현실 가격이라 작습니다(택시비 1만~3만 원, 밥값 1만 원). 이것만으로는 사람과 엮이는 직업이 혼자 알바보다 돈을 못 법니다.
- **해결:** 서비스 한 건마다 **시청이 수당을 줍니다.**
  - 대상: 택시 운행, 출장 수리, 식당 판매 등
  - 수입 = 손님이 낸 현실 요금 + 시청 수당
  - 그래서 사람과 엮이는 일이 혼자 알바의 1.2~1.5배가 됩니다.
- 수당은 회사 계좌로 들어가고, 사장이 직원 급여로 나눠 줍니다.
- 같은 사람끼리 수당만 노리고 반복하는 것은 막습니다. 같은 손님에게는 하루 몇 번까지만 수당을 줍니다.
- 손님 요금에는 운영진이 정한 상한을 둡니다.

### 4.6 운영 관리 [제안]
- 관리자 화면에서 서버 전체 돈의 양을 봅니다. 하루 동안 새로 생긴 돈과 빠져나간 돈도 함께 봅니다.
- 매주 점검하고, 시급과 가격은 설정 파일로 바로 조정합니다.
- 해외 경제 설계 가이드는 새로 생긴 돈의 60~70%를 회수해야 물가가 무너지지 않는다고 봅니다(05 문서). 이 비율을 기준으로 삼습니다.
- 돈 복사가 의심되는 이상 거래는 기록하고 알립니다.

## 5. 범죄·처벌표

### 5.1 원칙
- **범죄는 사람 경찰과 한 세트입니다.** 강도는 출근한 경찰 수에 따라 열립니다 [확정].
- 보상은 **검은돈**입니다. 붙잡히면 벌금, 감옥, 압수가 따릅니다.
- **보상과 처벌의 균형** [제안]
  - 범죄는 성공하면 혼자 알바보다 시간당 2~4배를 법니다.
  - 붙잡히면 손해를 봅니다.
- 새싹(🌱)을 상대로 한 범죄는 처벌을 2배로 합니다(형량 상한은 그대로).

### 5.2 범죄 종류 [제안]

**시작 조건 [확정]**
- 종류마다 최소 출근 경찰 수가 있습니다.
- 강도 인원은 출근 경찰 수를 넘을 수 없습니다(국내 일반 서버 시바 방식).
- 사람이 적은 시간에는 큰 강도가 열리지 않습니다. 의도한 것입니다.

| 범죄 | 장소 | 인원 | 최소 출근 경찰 | 쿨타임 | 보상 (검은돈, 팀 전체) |
|---|---|---|---|---|---|
| 편의점 강도 | 구역마다 있는 편의점 | 1~2명 | 2명 | 같은 편의점 30분 | 2,000만~3,000만 원 |
| 현금수송차 강도 | 이동 중인 현금수송차 | 2~3명 | 3명 | 서버 전체 20분 | 5,000만~8,000만 원 |
| 보석상 강도 | 명동(중구) | 2~4명 | 4명 | 60분 | 1억~2억 |
| 은행 지점 강도 | 중구·강남·송파 지점 (구역이 열리는 대로) | 3~4명 | 5명 | 지점마다 90분 | 2억~4억 |
| **은행 본점 강도** | 여의도 | 4~6명 | 8명 | 서버 전체 하루 2번 | 6억~12억 |
| 차량 절도 | 주차된 NPC 차 | 1명 | 1명 | — | 구인천 폐공장에서 해체하면 500만~3,000만 원 |
| 밀수 | 구인천 부두, 공항 세관 | 1~3명 | 2명 | 30분 | 운반 보수 |
| 가상 물질 제조·판매 | 북한산 은신처에서 제조, 거리에서 판매 | 1명~ | 판매만 2명 | — | 판매 금액 |

- **현금수송차 운전자**(혼자 하는 알바)는 강도를 당해도 자기 돈을 잃지 않습니다. 대신 위험 수당을 받습니다.
- 강도가 시작되면 경보와 함께 112 자동 신고가 갑니다(1단계에 이미 있음).

### 5.3 무기 [확정: 암시장에서만]
- **일반인은 총을 살 수 없습니다.**
  - 구인천 **암시장**에서만 구합니다. 암시장의 위치와 여는 시간은 가끔 바뀝니다 [제안].
  - 총을 들고 있는 것 자체가 범죄(불법 무기 소지)입니다.
- **경찰:** 계급별로 지급받습니다(3.3). 테이저는 경찰 전용입니다.
- **근접 무기(둔기·칼)** [제안]: 들고 다니는 것은 괜찮지만 휘두르면 폭행입니다.
- 지금 코드에 있는 「총포상 NPC」는 개발할 때 암시장으로 바꿉니다.

### 5.4 검은돈과 세탁 [확정: NPC + 조직 / 제안: 수치]
- **검은돈은 아이템입니다.**
  - 가방에 들고 다닙니다. 은행에 넣거나 가게에서 쓸 수 없습니다.
  - 경찰이 압수할 수 있고, 다른 사람이 빼앗을 수도 있습니다.
- **세탁 방법**

  | 방법 | 수수료 | 조건 |
  |---|---|---|
  | 구인천 NPC 세탁업자 | 40% | 누구나 |
  | 조직 아지트 | 20% | 그 조직원만, 하루 상한 있음 |

- 세탁은 맡긴 뒤 **10분쯤 지나야** 찾을 수 있습니다. 그 사이에 경찰 수사나 다른 조직의 습격 같은 RP가 생깁니다.

### 5.5 체포와 처분 [제안]
1. 수갑 (수갑을 채우면 권리 고지 메시지가 자동으로 나감)
2. 연행
3. 경찰차 뒷좌석에 태움
4. 수색·압수 (불법 물건, 검은돈)
5. **죄목 버튼 고르기**
6. 벌금·형량 자동 계산
7. 형량이 있으면 구인천 부두 호송선 → 섬 교도소
8. 경찰 단말기(MDT)에 기록

- **남용 방지**
  - 벌금과 형량은 죄목표대로 자동으로 정해집니다.
  - 경찰은 깎아 줄 수만 있고 늘릴 수는 없습니다.
  - 모든 처분은 기록되고, 이의 신청을 할 수 있습니다(7장).
- **벌금 처리**
  - 은행에서 자동으로 빠져나갑니다. 모자라면 미납으로 기록됩니다.
  - 벌금은 경찰에게 가지 않고 사라집니다(돈 회수).
  - 경찰은 벌금 액수와 상관없이 **체포 수당**을 정액으로 받습니다. 벌금을 많이 매길수록 이득이 되는 구조를 막기 위해서입니다.

- 검은돈은 모두 압수합니다.

### 5.7 감옥 [확정: 최대 30분 + 노역]
- **형량:** 구인천 앞바다 섬 교도소에서 실제 분 단위로 지냅니다. 접속해 있을 때만 줄어듭니다.
- **노역** [제안]
  - 청소, 세탁, 공장 작업 1건마다 형량이 1분 줄고 돈도 조금 법니다.
  - 감옥 안에서도 혼자 할 일이 있게 하려는 것입니다.
- **소지품:** 들어갈 때 불법 물건은 압수하고, 나머지는 보관했다가 나갈 때 돌려줍니다.
- **출소:** 배를 타고 구인천 부두에 내립니다.
- **탈옥** [제안]
  - 할 수 있습니다. 배를 구하거나 헤엄쳐야 합니다.
  - 출근 경찰이 2명 이상일 때만 할 수 있습니다.
  - 다시 잡히면 남은 형량에 탈옥죄가 더해집니다.

### 5.8 차량 절도 [제안]
- **NPC 차:** 락픽 미니게임을 합니다. 실패하면 경보가 울리고 자동 신고가 갑니다.
- **플레이어 차**
  - 훔쳐서 몰 수는 있지만 해체는 할 수 없습니다.
  - 주인 폰에 차 위치가 표시됩니다.
  - 일정 시간이 지나면 주인 차고로 돌아갑니다.

### 5.9 쓰러짐과 범죄 [제안]
- 쓰러진 사람의 검은돈과 불법 물건은 경찰이 압수하거나 다른 사람이 가져갈 수 있습니다.
- 병원에서 다시 깨어나면 그 사건은 잊습니다(뉴라이프, 7장 규칙).

| 강남 | 기업 본사들, 부촌, **경찰서(강남)** | 도시 유일한 경찰서 [확정]<br>플레이어 회사 본사, 고급 주택<br>수입차 대리점 |
| 송파 | 테마파크, 초고층 타워, 잠실 야구장 | 놀이와 행사(야구 미니게임), 전망대, 펜트하우스 |

구역마다 시작하는 혼자 하는 직업은 3.5 표의 「시작 위치」를 보세요.

**모든 구역에 고르게 둘 것** [제안]
- 편의점과 ATM: 강도 대상이 퍼져 있어야 경찰이 도시 전체를 돌아다닙니다.
- 주유소, 버스 정류장

### 6.3 사람이 몰리는 곳 나누기 (서버 렉 방지)
Folia는 서로 약 500블록 안에 모인 사람을 하나의 묶음(스레드 하나)으로 처리합니다. 그래서 늘 붐비는 곳은 서로 떨어뜨립니다.

- **늘 붐비는 곳:**
  - 공항(스폰), 여의도 광장(메인), 대학병원(부활)
  - 강남경찰서, 중구 기차역, 홍대 밤거리
  - 3.2×1.8km 크기에서는 대부분 450~700m 떨어져 있습니다. Folia 묶음 거리(약 500블록)와 비슷해서, 붐비면 거점 위치를 다시 조정합니다.
- **여의도** [제안]: 메인이라 가장 붐빕니다. 섬 안에서도 광장·은행 본점·방송국을 서쪽·가운데·동쪽으로 나눠 띄웁니다. 도시가 작아져서 간격은 약 180m입니다.
- 병원을 여의도에서 대학교로 옮긴 것도 같은 이유입니다 [확정].

### 6.4 도로 (스케치 기준)

| 종류 | 스케치 색 | 내용 | 폭 [제안] |
|---|---|---|---|
| 고속도로 (기존) | 빨강 | 한강 양쪽 강변도로, 공항까지 가는 고속도로, 남쪽 외곽 도로. 실제 도로를 본뜹니다 | 왕복 6차로 + 중앙분리대 |
| 대로 (신규) | 주황 | 구역과 구역을 잇는 큰길 | 왕복 4~6차로 + 인도 |
| 중로 (신규) | 회색 | 구역 안의 길. 모든 구역에 격자로 깔았습니다 [확정] | 대로와 같은 왕복 4차로 + 인도 [확정: 고속도로 외 통일] |
| 남산터널 | 보라 점선 | 중구에서 남산을 지나 한강 쪽으로 | 왕복 2차로 |
| 일반 대교 (기존) | 노랑 | 여의도와 강남북을 잇는 한강 다리들 | 왕복 4차로 |

[제안] 1차로는 **4블록**으로 합니다. 실제 3.5m보다 조금 넓혀서 마인크래프트에서 운전하기 편하게 합니다.

### 6.5 이동 수단 [제안]
- **공항철도·공항버스:** 공항에서 중구 기차역까지 갑니다. 요금을 내고 클릭하면 이동합니다.
- **택시:** 플레이어 택시 회사만 있습니다. 폰 「호출」 앱으로 부릅니다(3.4).
- **뉴비 렌트카:** 두지 않습니다. 정착금과 알바 1시간이면 경차를 살 수 있습니다(2.4).

### 6.6 한 번에 전부 열기 [확정]
오픈 때 **도시 전체(15개 구역 + 교도소 섬)를 한 번에 엽니다.** 구역별 오픈 차수는 두지 않습니다.

- 생성기가 모든 구역의 거리(빌라, 상가, 거리 시설)를 자동으로 지어서, 구역 하나를 채우는 비용이 작습니다.
- 직업과 거점을 원래 있어야 할 곳에 그대로 둘 수 있습니다 (나무꾼·광부는 북한산, 농부·축산은 청라).
- 랜드마크와 새 콘텐츠는 업데이트마다 추가합니다.

### 6.7 맵 만드는 방법 (스케치에 맞춰 변경)
배치를 새로 짠 지도라서, 실제 지도를 통째로 생성하는 방식(`03-도시맵-제작.md` 2장)은 **그대로 쓸 수 없습니다.** 대신 아래 순서로 만듭니다.

1. **바탕 지형:** 스케치를 3.2×1.8km로 옮겨 한강, 바다, 산(북한산·남산)을 만듭니다. (생성기로 자동, `06-맵-설계도.md` 7장)
   - WorldPainter 같은 지형 도구를 씁니다. 26.x 지원 여부는 쓰기 전에 확인합니다.
2. **도로 먼저:** 고속도로, 대로, 다리, 터널을 깝니다. 도로가 곧 구역의 경계가 됩니다.
3. **구역 채우기:** 실제 동네를 Arnis로 1:1 생성한 다음, 필요한 부분(0.5~1km)만 잘라 붙입니다(MCA Selector·WorldEdit).
   - 실제 동네는 우리 구역보다 크기 때문에 핵심 부분만 가져옵니다.
   - 경계와 도로 연결은 손으로 다듬어야 합니다.
4. **랜드마크는 직접 짓습니다:** 남산타워, 금융 타워, 방송국, 공항 터미널, 돔구장, 초고층 타워, 교도소 등
5. **건축 서버와 운영 서버를 나눕니다:** Paper 건축 서버에서 짓고, 완성되면 Folia 운영 서버로 복사합니다(`03-도시맵-제작.md` 4장).

### 7.1 서버 규칙 [제안: 문구]
입국 심사 화면에 같은 내용을 보여 주고 동의를 받습니다(2.2).

| 분류 | 규칙 |
|---|---|
| RP 기본 | 이유 없이 죽이기·차로 치기 금지 (RDM·VDM)<br>죽었다 깨어나면 그 사건 잊기 (뉴라이프)<br>게임 밖 정보 쓰지 않기 (메타게임)<br>현실에서 불가능한 행동 금지 (파워게임)<br>총이 겨눠지면 목숨 아끼기 |
| 사람 보호 | 새싹(🌱) 괴롭히기 금지<br>의료국 공격 금지 (중립)<br>불리할 때 접속 끊고 도망가기 금지 |

### 7.2 처벌 [확정: 운영진 재량]
- 운영진이 상황을 보고 경고, 관리자 감옥, 기간 정지, 영구정지 중에서 정합니다.
- 핵·모드·현금 거래는 영구정지를 기본으로 합니다 [제안].
- **영구정지 해제 [확정]:** 반성문을 내면 운영진이 검토해서 풀어 줄지 정합니다.
- **편파 의혹을 줄이는 장치** [제안]
  - 재량은 유지하면서 아래 장치를 둡니다. 국내 일반 서버 불만 1위가 운영 편파였기 때문입니다(05 문서).
  - 모든 처벌에 사유와 근거(서버 기록)를 남기고, 처벌받은 사람에게 알립니다.
  - 이의 신청은 처음 판정한 운영진이 아닌 다른 운영진이 다시 봅니다.
  - 운영진끼리 참고할 과거 처벌 사례 목록을 둡니다(내부용).

### 7.3 신고와 판정 [제안]
1. 폰 「관리자 호출」 앱에서 신고 사유를 버튼으로 고르고, 주변 사람 중 대상을 고릅니다.
2. 최근 5분의 서버 기록이 자동으로 붙습니다. 위치, 킬·피격, 차 충돌, 채팅입니다.
3. 운영진은 게임 안 신고 목록과 디스코드 알림으로 받아서 처리합니다.
4. 결과와 사유를 신고한 사람과 신고당한 사람에게 알립니다.
5. 이의 신청은 디스코드 티켓으로 하고, 다른 운영진이 다시 봅니다.

### 7.4 서버 기록과 자동 처리
- **도망 접속 자동 처리 [확정]**
  - 수갑을 찬 채, 쓰러진 채, 싸우는 중(최근 30초 안에 공격하거나 맞음)에 접속을 끊으면 기록이 남습니다.
  - 다시 들어오면 **그 자리, 그 상태 그대로** 돌아옵니다.
  - 처벌 여부는 운영진이 기록을 보고 정합니다.
- **기록 대상** [제안]
  - 킬·피격, 차 충돌, 채팅(OOC 포함), 위치, 접속·종료
  - 돈 거래, 체포·벌금은 이미 기록하고 있습니다.
  - 보관 기간은 30일입니다.
- **운영진 자동 알림** [제안]
  - 짧은 시간에 여러 명을 죽이거나 차로 친 경우
  - 수상한 돈 흐름(4.6)
  - 매크로·잠수 패턴
- 유저에게 녹화를 강요하지 않습니다. 개인 영상은 참고 자료로 낼 수 있습니다.

### 7.5 운영진 [확정: 캐릭터 플레이 금지]
- **운영진은 캐릭터로 RP에 참여하지 않고 관리만 합니다.** 헬퍼도 포함합니다.
  - 뉴비 도우미(3.1)는 운영진이 아니라 플레이어가 맡는 직업입니다.
- **관리 모드** [제안]: 투명, 관전, 순간이동, 기록 보기, 신고 처리
- **구조** [제안]: 운영자 → 관리자 → 헬퍼
  - 헬퍼는 뉴비 질문과 가벼운 신고를 맡습니다.
- **인원 목표** [제안]: 동접 50명당 관리자 1명, 헬퍼 2명
- 자기 지인이 얽힌 사건은 판정하지 않습니다 [제안].
- 운영진은 경찰청장과 병원장을 임명만 하고(3.2), 게임 안 직책은 맡지 않습니다.

### 7.6 소통 [제안]
- **디스코드 채널:** 공지, 업데이트 노트, 신고·이의 신청 티켓, 공무직·회사·조직 지원, 자유 채팅(OOC), 건의
- **업데이트와 행사 일정은 미리 공개합니다.** 업데이트 노트는 2주마다 냅니다.
