## 1. 컨셉 [확정]

| 항목 | 결정 |
|---|---|
| 도시 배경 | 서울과 인천을 한 장에 압축한 가상 수도권입니다. GTA의 로스산토스가 LA를 압축한 것과 같은 방식입니다 |
| 이용 연령 | **15세 이상** |
| 콘텐츠 수위 | 총·강도·갱은 있습니다. 마약은 가상 물질로 순화하고, 선정적인 내용은 없습니다 |
| 입장 방식 | **누구나 바로 입장** (화이트리스트 없음) |
| 규칙 교육 | 입국 심사의 동의 버튼 (지금 방식 그대로) |
| 지명·상호 | 지명은 실제 그대로 씁니다. 가게·브랜드 이름과 로고는 패러디로 바꿉니다 |
| RP 수준 | 엄격과 라이트 사이 |
| 운영 목표 | **공개 서버로 키우기.** 후원으로는 꾸미기 아이템만 팝니다. 돈·차·무기처럼 게임에 유리한 것은 마인크래프트 규정상 팔 수 없습니다 |
| 규모 | 동접 500명, 하나의 큰 도시 (Folia 단일 월드) |
| 음성·리소스팩 | 근접 음성(Simple Voice Chat)과 리소스팩을 씁니다 |

### 이 결정 때문에 해야 할 일 [제안]
- **누구나 들어오므로 운영 도구를 일찍 준비합니다.**
  - 폰 신고 앱, 경고 누적, 관리자 감옥
  - 행동 기록: 누가 누구를 죽였는지, 차로 쳤는지
- **규칙 교육이 동의 버튼뿐이므로**, 처음 규칙을 어기면 바로 처벌하지 않고 어떤 규칙인지 알려 주는 안내부터 띄웁니다.
- **뉴비 보호:** 처음 몇 시간은 공격받지 않거나 범죄 콘텐츠를 쓸 수 없게 할지 2장(플레이어 여정)에서 정합니다.

## 6. 도시 맵 v1

### 6.1 한눈에
- **배치 [확정]:** 운영자 스케치(2026-10-04)를 따릅니다.
  - 한강이 도시 가운데를 가로지르고, **여의도가 도시의 중심(메인)**입니다.
  - 강북: 북한산, 마포구, 홍대, 중구, 용산, 남산, 광진구
  - 강남: 대형시장, 대학교, 강남, 송파
  - 서쪽 끝: 구인천, 청라, 공항, 앞바다의 교도소 섬
  - 종로는 뺐고, 그 자리는 중구와 북한산으로 채웁니다.
- **크기 [확정]:** 약 **9×5km** (1블록 = 1m)이고, 구역 하나는 1~2km입니다.
  - [제안] 서쪽 바다와 교도소 섬까지 넣으면 월드 경계는 약 10×6km입니다.
- **이동 시간** (지금 차 속도 기준)

  | 수단 | 동서 끝에서 끝까지 |
  |---|---|
  | 세단 (72km/h) | 약 7~8분 |
  | 스포츠카 (100km/h) | 약 5~6분 |
  | 뛰기 | 약 27분 |

- **높이 [제안]:** 마인크래프트는 높이 한계가 있습니다.
  - 북한산(실제 836m)과 송파 초고층 타워(실제 555m)는 300m 안팎으로 줄입니다.
  - 남산(262m)은 거의 실제 높이로 만듭니다.

### 6.2 구역표

| **공항** | 터미널, 세관, 활주로 | **스폰과 입국 심사** [확정]<br>세관: 밀수 단속<br>공항철도·버스로 시내 이동 |
| 청라 | 대형 쇼핑몰, 돔구장, 신도시 분양 필지 | 플레이어 땅 분양(집 짓기), 쇼핑, 큰 행사장 |

**모든 구역에 고르게 둘 것** [제안]

- 주유소, 버스 정류장

### 6.3 사람이 몰리는 곳 나누기 (서버 렉 방지)
Folia는 서로 약 500블록 안에 모인 사람을 하나의 묶음(스레드 하나)으로 처리합니다. 그래서 늘 붐비는 곳은 서로 떨어뜨립니다.

- **늘 붐비는 곳:**
  - 공항(스폰), 여의도 광장(메인), 대학병원(부활)
  - 경찰서 2곳(용산·강남), 중구 기차역, 홍대 밤거리
  - 9×5km 크기에서는 대부분 자연스럽게 1km 이상 떨어집니다.
- **여의도** [제안]: 메인이라 가장 붐빕니다. 섬 안에서도 광장·은행 본점·방송국을 서쪽·가운데·동쪽으로 나눠 서로 500m 이상 띄웁니다.
- 병원을 여의도에서 대학교로 옮긴 것도 같은 이유입니다 [확정].

### 6.4 도로 (스케치 기준)

| 종류 | 스케치 색 | 내용 | 폭 [제안] |
|---|---|---|---|
| 고속도로 (기존) | 빨강 | 한강 양쪽 강변도로, 공항까지 가는 고속도로, 남쪽 외곽 도로. 실제 도로를 본뜹니다 | 왕복 6차로 + 중앙분리대 |
| 대로 (신규) | 주황 | 구역과 구역을 잇는 큰길 | 왕복 4~6차로 + 인도 |
| 중로 (신규) | 회색 | 구역 안의 길 | 왕복 2~4차로 + 인도 |
| 남산터널 | 보라 점선 | 중구에서 남산을 지나 한강 쪽으로 | 왕복 2차로 |
| 일반 대교 (기존) | 노랑 | 여의도와 강남북을 잇는 한강 다리들 | 왕복 4차로 |

[제안] 1차로는 **4블록**으로 합니다. 실제 3.5m보다 조금 넓혀서 마인크래프트에서 운전하기 편하게 합니다.

### 6.5 이동 수단 [제안]
- **공항철도·공항버스:** 공항에서 중구 기차역까지 갑니다. 요금을 내고 클릭하면 이동합니다.
- **택시:** 플레이어 택시 회사와 NPC 택시 중에서 3장에서 정합니다.
- **뉴비 렌트카:** 처음 접속하면 일정 시간 빌려줍니다(설계 문서 4.1).

### 6.6 나눠서 열기 [제안]
9×5km를 한 번에 다 지으면 오픈이 늦어집니다. 꼭 필요한 구역부터 열고, 월드 경계를 넓히면서 추가합니다.

| 차수 | 구역 | 이유 |
|---|---|---|
| 1차 오픈 | 공항, 여의도, 중구, 용산, 대학교, 구인천 + 교도소 섬, 대형시장 | 스폰, 메인, 행정, 경찰, 병원, 범죄, 알바가 한 바퀴 돕니다 |
| 2차 | 강남, 홍대, 마포구, 남산 | 경찰서 2곳 체제, 밤문화 |
| 3차 | 송파, 청라, 광진구, 북한산 | 주거·분양, 행사장, 은신처 |

### 6.7 맵 만드는 방법 (스케치에 맞춰 변경)
배치를 새로 짠 지도라서, 실제 지도를 통째로 생성하는 방식(`03-도시맵-제작.md` 2장)은 **그대로 쓸 수 없습니다.** 대신 아래 순서로 만듭니다.

1. **바탕 지형:** 스케치를 9×5km로 옮겨 한강, 바다, 산(북한산·남산)을 만듭니다.
   - WorldPainter 같은 지형 도구를 씁니다. 26.x 지원 여부는 쓰기 전에 확인합니다.
2. **도로 먼저:** 고속도로, 대로, 다리, 터널을 깝니다. 도로가 곧 구역의 경계가 됩니다.
3. **구역 채우기:** 실제 동네를 Arnis로 1:1 생성한 다음, 필요한 부분(1~2km)만 잘라 붙입니다(MCA Selector·WorldEdit).
   - 실제 동네는 우리 구역보다 크기 때문에 핵심 부분만 가져옵니다.
   - 경계와 도로 연결은 손으로 다듬어야 합니다.
4. **랜드마크는 직접 짓습니다:** 남산타워, 금융 타워, 방송국, 공항 터미널, 돔구장, 초고층 타워, 교도소 등
5. **건축 서버와 운영 서버를 나눕니다:** Paper 건축 서버에서 짓고, 완성되면 Folia 운영 서버로 복사합니다(`03-도시맵-제작.md` 4장).
